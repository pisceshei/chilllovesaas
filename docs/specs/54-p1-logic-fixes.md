**最終公式（`Checkout::ShippingRateMerger`，全程 integer cents、無捨入點）**

```
# 參與者：合併的最小單位是 (設定檔 × location group)，不是設定檔、也不是地點
P = { (profile_id, location_group_id) | 該 pair 至少負責購物車中一個 line item 的出貨 }

# 每個 participant 各自解析候選費率（條件以「p 自己負責的那批品項」判斷）
Rates(p) = { (name, price_cents) | rate 屬於 p 的 zone 且條件成立 }
parcel_weight_grams(p) = Σ_i(item_weight[i] × qty[i]) + shop.default_package_weight_grams   # 每個 p 各加一次

key(rate)   = NFC(trim(rate.name))        # 合併鍵＝費率名稱，大小寫敏感
Names(p)    = { key(r) | r ∈ Rates(p) }
CommonNames = ⋂_{p ∈ P} Names(p)          # 交集：必須「每一個」participant 都有這個名字

if CommonNames ≠ ∅:                        # 分支 1：名稱相同者相加
    options = { n ↦ Σ_{p ∈ P} price_of(p, n)  |  n ∈ CommonNames }   # 不在交集內的名稱一律丟棄
else:                                      # 分支 2：名稱全不同 → 各取最便宜再相加
    options = { single ↦ Σ_{p ∈ P} min{ r.price_cents | r ∈ Rates(p) } }

# 例外：Rates(p) = ∅（該 participant 無可用費率）⇒ 整車不可配送到此地址，結帳擋下（不是當作 0 元）
# 順序：合併（第 4 步產生配送選項）→ 運費折扣（第 5 步）→ 稅。免運折扣打在合併後的金額上。
```

|---|---|---|---|

| **2** | **三檔名稱全不同** | P1 `標準宅配` 8000／`快遞` 15000；P2 `低溫宅配` 18000；P3 `大型物流` 35000／`大型物流-偏遠` 45000 | `CommonNames=∅` → **單一選項 8000+18000+35000 = 61000** |
| **3** | **部分同名部分不同** | P1 `標準宅配` 8000／`快遞` 15000；P2 `標準宅配` 6000／`貨到付款專用` 9000；P3 `標準宅配` 5000／`快遞` 12000 | `CommonNames={標準宅配}`（`快遞` 缺 P2）→ **只有 `標準宅配` 19000**；`快遞` **不出現** |
