# 22 — Admin 按鈕級功能對照與實作註釋

> 來源：help.shopify.com 官方手冊 80+ 頁逐頁挖掘（2026-08）+ 21 號實測 teardown。**這是正式開發的快速對照表**：每個控制項標註「功能 → 邏輯規則 → 實作註釋」。實作註釋代號：`M`=資料模型（06 號文件）、`S`=生產級規格（11–19 號）、`API`=API 層（09 號）、`P0/P1/P2`=優先級（07 號）。v2 原型已內建「**開發註釋模式**」——開啟後點任何虛線框元素即顯示本文件的對應註釋。

## 0. 通用 Shell 與橫切機制

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|
| 全域搜尋（CTRL K） | 跨資源搜尋+快速跳轉；支援結構化語法（`title:xxx`、`tag:值`、萬用字元、AND/OR/NOT） | P1。搜尋服務：各資源 FULLTEXT（S14-F4 ngram）+ 前綴語法解析器；先做 訂單號/商品/顧客 三類 |
| 檢視系統（saved views） | 每列表：預設檢視+自訂檢視（儲存篩選+排序+**欄位設定**），可改名/複製/刪除/釘選 | P0。M：`saved_views(staff_id, resource, filters_json, sort, columns_json)`；預設檢視唯讀 |
| 篩選器引擎 | 條件間 AND、同條件多值 OR；訂單可按狀態/金額/管道/標籤/風險/卡末四碼/metafield 等 20+ 維度 | P0 核心維度、P1 長尾。查詢建構器把 filters_json 轉 SQL（白名單欄位，防注入 S11§1） |
| 匯出對話框 | 範圍四選一（本頁/全部/勾選/目前篩選）+ 格式；**>50 筆改寄 email 下載連結**（10 萬筆約 1 小時） | P1。S13-F6：streaming CSV + job + 簽名下載連結；小量同步、大量轉背景寄信 |
| 匯入 CSV | 15MB 上限；欄名區分大小寫；「覆寫相同 handle/email」勾選；**欄留空=清空、整欄省略=保留** | P1。S13-F6 逐行 job + 錯誤報告；「空值 vs 缺欄」語意要寫進測試 |
| 批次編輯器（bulk editor） | 類試算表：欄位增減、方向鍵、拖曳填滿、需按 Save | P1。前端表格（TanStack）+ 一支 bulk PATCH（逐列驗證回錯 S13-F1） |
| 時間軸留言 | @提及員工（寄通知）、# 引用資源、附件、emoji；發布後 5 分鐘可編輯、僅本人 | P0 基本留言；提及/引用 P1。M：events + mentions 表；S16-F2 append-only |
| 動作可見性 | 未授權的模組整個選單不可見（非灰化） | S12-F3：Pundit + 側欄按權限渲染 |

## 1. 訂單

### 1a. 列表

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|
| 批次動作 | 出貨類（標記出貨/處理中/未出貨/**on hold（選原因）**/變更地點）、capture（僅全額）、列印裝箱單、標籤、封存 | P0：批次出貨/封存/標籤。批次逐筆獨立 transaction+結果報告（S16-F1）；批次出貨不能填追蹤碼（事後逐筆補）——照抄此取捨 |
| 匯出交易歷史 | 獨立按鈕；只含已 capture 交易 | P2。transactions 表直出（M：order_transactions） |
| 風險警示 | 中高風險單號旁 icon | P0 欄位預留；模型 P2（S15-F4 假指標起步） |

### 1b. 訂單詳情

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|
| Refund | 逐行數量、restock 勾選（追蹤庫存才顯示）、退運費（上限=原收；免運單不可退運費）、可改總額、多付款方式分配、通知勾選；**不可超過實收**；退款後不能再建退貨 | P0。S16-F5 全套：先落 pending 再打金流、restock 以 refund_line_item 冪等、上限=Σcaptured−Σrefunded |
| Edit（編輯訂單） | 加品項/自訂品項/調量/移除未出貨項/品項折扣 → 差額：多收→寄發票或收款、少收→退款；**不能改訂單層折扣**；已出貨項不可移除；分期付款單不可編輯；稅重算、運費不重算 | P1。金額引擎重算（S15-F2）+ 差額發票流；限制清單直接做成 guard 函式 |
| Duplicate | 以現單開新草稿：帶品項（取最新商品資料）、顧客、地址、備註、標籤；**折扣與運費不複製** | P1。`Orders::Duplicate` → draft_orders |
| Cancel | 對話框：退款方式（原路/店內額度/稍後）、原因必選、restock 預設勾、通知預設勾；部分出貨後不可取消；未 capture→Voided、已收→Refunded | P0。S16-F4 狀態條件轉移 + 庫存釋放 + void/refund 分流 |
| Archive/自動封存 | 手動或設定觸發（已付+已出貨或全退） | P0 手動；自動＝nightly job（S16-F4） |
| 裝箱單 | Liquid 模板可自訂、可還原預設；多段出貨=多張 | P1。notification_templates 同機制（S18-F2） |
| Fulfill 卡 | 數量（部分出貨）、追蹤碼（自動辨識物流商+可多筆）、通知勾選；**on hold 須先解除**；最多 10 個手動 hold；拆分/合併出貨；Mark as delivered；取消出貨（先 void 標籤） | P0：數量+追蹤+通知。M：fulfillment_orders（hold 狀態+reasons 表）；carrier 自動辨識=正則表 P1 |
| 買運送標籤 | 包裹尺寸/總重/寄件日/服務選擇/跨國報關欄（HS+申報價值+產地）/保險 → 費用記平台帳單、自動標出貨+回填追蹤 | P2（接物流商 API）。介面先留 `Labels::Quote/Purchase` adapter |
| Capture | Authorized 區顯示；可部分 capture（可多次，依供應商）；**授權期 7 天**（到期前 2 天示警）；批次只能全額 | P1（Stripe manual capture）。S15-F4：授權到期提醒＝nightly job + banner |
| Collect payment | 寄請款信 / 手輸卡號 / Mark as paid（外部已收款，不再請款） | P0：Mark as paid + 請款信。draft/pending 訂單共用 |
| 顧客區編輯 | 換/移除顧客（僅解除連結）；改聯絡（可勾同步回顧客檔）；改收件地址→**重算稅並產生差額卡**；帳單地址不可改 | P1。地址改→金額引擎重算→差額流程（同 Edit） |

### 1c. 草稿訂單

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|
| 自訂品項 | 名稱/單價/數量/課稅/是否實體；不入目錄不影響庫存報表 | P1。M：line_items.custom=true |

| 折扣/運費 | 碼或自訂（訂單層/品項層+原因）；運費選店費率（需地址）或自訂 | P0。重用折扣引擎+RateResolver |
| Payment due later | 帳期（收貨即付/出貨後/Net 7–90/固定日）；Plus 可要求訂金 | P2。M：draft_orders.payment_terms |
| Send invoice | 自訂訊息、允許輸碼開關、忽略結帳驗證勾選 → 顧客付款轉正式單 | P0。簽名結帳連結（S15-F3 checkout 複用） |

### 1d. 棄單 / 退貨

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|
| 棄單列表 | 只列：留 email、≥10 分鐘、非 bot、線上通路；3 個月自動刪；寄挽回信（手動/自動：對象+延遲+模板）；可轉草稿保留 | P0 列表+手動信；自動化 P1（S15-F7 全套） |
| Return 建立 | 選品項+原因（依品類動態）→ 退貨運送三選一（平台標籤/上傳標籤/無需寄回）→ restocking fee 與退貨運費按規則帶入（可逐單改）→ Exchange 加購（算差額；不能自訂品項）→ 收貨 accept/restock → 退款 | P1。M：returns + return_rules 表；S16-F5；「退貨費不自動從退款扣」照抄 |
| Return rules | 退貨期限（14/30/90/自訂，自送達起算）、restocking fee %、退運費歸屬、Final sale 排除品 | P1。settings 域 + 顧客自助退貨（P2）共用 |

## 2. 產品

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|
| 描述富文本 | 全工具列 + 圖/影/表格 + HTML 檢視；**64KB 上限**；HTML 自動消毒 | P0。TipTap + sanitize（S13-F1 白名單）+ 大小限制 |
| AI 生成描述 | 依關鍵字/語氣生成草稿 | P2（AI 助理家族） |
| 媒體 | **上限 250**；首位=精選圖；圖 ≤20MB/≤25MP；影 ≤1GB/10 分；3D ≤500MB；alt 可編；拖曳排序 | P0 圖片；影/3D P2。S13-F3 全套（direct upload/尺寸驗證/EXIF） |
| 類別 taxonomy | 標準分類 1 個；解鎖類別 metafields、影響稅則 | P2。M：products.category_id + 標準分類表 |
| 定價 | compare-at > price 才顯示特價；**系列頁 Sale 標籤需全變體 compare-at 一致**；cost 算毛利不對外 | P0。展示規則進 storefront helper（S14） |
| 庫存卡 | SKU/條碼（真實 GTIN 供通路）/track 開關/繼續銷售/五狀態量 | P0。M：inventory_*（S13-F5） |
| 變體 | ≤3 選項/≤2048 變體；選項與值可重排改名；**改選項會重建變體**（斷外部引用）；批改價格/圖片/庫存；依選項分組 | P0。S13-F1 diff 更新（不重建）——我們刻意優於本尊的點，註明差異 |
| SEO 編輯 | 標題 ≤70、描述 ≤320、handle 改時「建立轉址」勾選 | P0。S13-F2 redirect 表 |
| 狀態 | Active/Draft/Archived + **Unlisted**（可直連買、不可被發現 noindex） | P0 三態；Unlisted P1（publishing 加 flag） |
| 發布 | 管道與市場清單、**排程上線日期**、變體層級可單獨發布 | P0 管道；排程 P1（publish_at + job） |
| Duplicate | 對話框勾選複製範圍（圖/SKU/條碼/庫存量）+ 複本狀態；影片/3D 不複製 | P1。`Catalog::Duplicate` |
| 封存 vs 刪除 | 封存=下架保留（可回復）；刪除=永久 | P0。被 line_items 引用禁止硬刪（S13-F1） |
| 系列 | 手動 vs 智慧**不可互轉**；智慧：≤60 條件、全店智慧系列 ≤5,000、比對欄位+運算子枚舉（equals/greater/starts/contains/set…）；排序 8 種（手動才可拖曳）；每系列可選管道+排程+SEO | P0 手動+簡化智慧；S13-F4 物化策略；運算子枚舉照 API 清單 |
| 庫存頁 | Available/On hand 可就地編；**Adjust by vs Set to** 兩模式；原因 7 種；調整歷史（180 天，更久用報表）；匯入僅 On hand 可寫 + 防過期校驗欄 | P0。ledger（S13-F5）+ 歷史頁；「on hand(current) 防過期校驗」是漂亮的併發防呆，抄 |
| 轉移 | Draft→Ready（保留庫存）→In transit（記 Incoming）→收貨 accept/reject 可部分；Draft 才可刪 | P1。M：transfers；狀態機進 06 §4 |
| 採購單 | 供應商檔案+成本+付款條件；Mark as ordered 後連結轉移收貨 | P2 |
| 禮品卡 | 面額=變體；後台直接發卡（≤$2,000、需 email/電話）；**停用=永久**；改到期日；完整卡號僅顧客可見（後台只見末 4 碼） | P1。M：gift_cards（code digest 存法同 api_tokens S19-F5） |

## 4. 折扣

| 控制項 | 功能與邏輯 | 實作註釋 |
|---|---|---|

| 列表管理 | 停用/重啟（批次有狀態限制）、複製、刪除、篩選存檢視、詳情時間軸 | P0 基本；時間軸掛 events |
