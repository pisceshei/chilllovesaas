### §0.2 🔴 內嵌 app 邊界（本輪重大架構發現）
**`/themes` 與 `/online_store/preferences` 不是原生 admin 頁，而是內嵌 app 頁**：內容由
`online-store-web.shopifyapps.com` 在**跨域 iframe** 中渲染（實測 iframe 768×483、visible）。
- 直開該 iframe 來源 URL 回 `{"message":"HMAC validation failed"}`——證明它靠 admin shell 傳簽章參數。
- ⚠️ **teardown 工具限制**：自動化瀏覽器 session 內該 iframe 不繪製（內嵌 app 握手過不了），
  **看到的空白是工具限制、不是商店狀態**。2026-08-13 首次誤判為「條件性閘門」，同日更正。
  ⇒ 這兩頁的控件事實**以 help 為準**（§3、§4），實測待使用者側一般瀏覽器補截圖。
- **架構含義**：Shopify 自己把線上商店做成「銷售管道 app」——我方 M2 主題引擎若照此拆，
  等於把前台管理面做成獨立服務。**是否照抄此邊界待裁定（71-R9-V1）**。

## §1 內容 › 元物件（條目層；定義層在設定，77 §… R3 已記）

- **分工邊界**（help 明文）：**定義管理在「設定 > 自訂資料」；項目管理在「內容 > 元物件」**——
  同一資源兩個入口（schema vs data）。
- 條目建立流程 8 步：進內容>Metaobjects → 選定義 → 新增項目 → 填欄位 → （標準 metaobject 才有）
  選 Base 值 → 設狀態 → （選填）改 Handle → （選填）選佈景主題範本 → 儲存。
- **狀態值域【窮舉：2 值】**：啟用（可在商店顯示，發布後顧客才可見，**預設**）／草稿（無法發布）。
- Handle：自動產生、鉛筆可改；「編輯已發布項目的控制代碼可能導致 Liquid 發生錯誤」。
- 條目詳情有**佈景主題範本選擇器＋眼睛預覽**；刪除條目不可復原且從所有已發布位置移除。
- 發布為網頁三階段：定義啟用店面存取＋勾「將條目發布為網頁」＋指定頁面標題/中繼說明欄位 →
  建條目 → 佈景主題編輯器建同名範本（**系統自動用定義名作範本名**）。
- 連接佈景主題**三法【窮舉】**：連到區塊／連到支援「動態來源」的設定／Liquid 程式碼。
  限制：只能連到**區塊**、型別須相符、需 Online Store 存取權。
- 參考：中繼欄位選 Metaobject 型別，可單值或清單；**混合式參考**只能經 Liquid/Storefront API，
  管理介面不可直接操作。

## §2 內容 › 檔案

- 實測頁首雙鈕：**從網址上傳／上傳檔案**；列表欄七：縮圖/檔案名稱/替代文字/新增日期/大小/參照/操作。
- **支援格式與上限【窮舉】**：圖片 JPEG/PNG/WEBP/HEIC/GIF（≤20MB、≤20MP）；影片 MOV/MP4/WEBM
  （≤1GB、≤10 分鐘、UHD）；一般檔案除 HTML 外任意（≤20MB）。**一次最多 20 檔**。
  試用方案受限格式：JS/CSS/GIF/JPEG/PNG/JSON/CSV/PDF/WebP/HEIC。
- **篩選器【窮舉：4】**：File size（範圍）／File type／Used in（引用處）／Alt text；支援 is/is not＋or/and。
- **排序【窮舉：3 鍵×2 向】**：Date added（Newest/Oldest first，**預設 Oldest first**）／
  File name（A-Z/Z-A）／Size（Smallest/Largest first）。
- **逐檔動作【窮舉】**：重新命名／取代／新增替代文字／設定焦點(focal point)／更新影片封面／
  複製連結／下載原始媒體；大量動作：Delete files。欄可隱藏與重排（最左欄除外）。

## §4 線上商店 › 佈景主題（內嵌 app，事實以 help 為準）

- 頁面分區：**已發布佈景主題**／**草稿佈景主題**（明文區段名）。
- **程式碼編輯器資料夾【窮舉：7】**：Layout／Templates／Sections／Snippets／Assets／Config／Locales。
- **程式碼動作【窮舉】**：編輯程式碼／儲存(⌘S)／新增檔案／上傳(僅 Assets)／重新命名／永久刪除／
  還原內容（時間軸復原；**一次僅能還原一個檔案，Assets 無版本記錄**）。
- **範本類型【窮舉：11】**：產品／商品系列／商品系列清單／禮品卡／頁面／購物車頁面／網誌／
  網誌文章／搜尋頁面／密碼頁面／**404 頁面**。**範本總數上限 1,000**。
- **區段與區塊上限【窮舉：3 條】**：每範本 ≤25 區段／每範本跨區段 ≤1,250 區塊／巢狀 ≤8 層。
- **區塊來源【窮舉：3 類】**：App blocks／Section blocks／Theme blocks（支援巢狀）。
- 市場層覆寫：**Advanced/Plus 專屬**；覆寫三層級（個別設定／區段或區塊／範本或區段群組）；
  **最多 250 個市場**。
- 密碼頁：**啟用/停用在偏好設定、視覺編輯在佈景主題**（雙入口）；可編輯區段三：密碼頁首／
  電子郵件訂閱橫幕／密碼頁尾。移除密碼保護需**先選定價方案**（試用期不能移除）。
- robots.txt.liquid：新增範本流程（編輯程式碼→新增範本→選 robots→建立範本）；
  **可自訂 4 類**（允許/禁止網址、crawl-delay、額外 sitemap、封鎖爬蟲）；
  預設 Disallow：/admin、/cart、/checkout、/collections/*+*、/search、/policies/；
  ⚠ 官方標明 unsupported customization，且**綁在已發布佈景主題**（換主題＝換規則）。

## §5 線上商店 › 頁面／偏好設定（以 help 為準）

- 頁面：列表→編輯器（標題/內容 RTE/可見性含排程/**佈景主題範本下拉**/SEO 編輯區）；
  批次動作「設為可見／設為隱藏」。
- 偏好設定內容（help）：標題與中繼說明／**社群分享圖片**（fallback 優先序：佈景主題程式碼 >

  給訪客的訊息）／Spam 防護。
- **加速結帳按鈕【窮舉】**：Amazon Pay／Apple Pay／Google Pay／PayPal／Shop Pay／Venmo＋無品牌
  「立即購買」；顯示集合隨訪客瀏覽器/裝置/付款記錄/Shop Promise 狀態**動態變化**。

## §6 店面搜尋與其他（critic 補抽，我方 M2 前台相關）

- **可搜尋資源【窮舉：3】**：產品／頁面／網誌文章；各自可搜欄位（產品 8 欄：body/product_type/
  tag/title/variants.barcode/variants.sku/variants.title/vendor）。
- **搜尋語法【窮舉】**：AND(預設)／OR／NOT(減號)／前綴(自動)／片語(雙引號)／欄位:字詞。
  前綴搜尋最多 50 筆相符。
- 預測性搜尋回傳 5 類（商品/頁面/網誌文章/商品系列/查詢建議），預設合計 ≤10 筆。
- **noindex 只擋外部搜尋引擎，內容仍出現在店面搜尋**——兩套獨立可見性開關（我方 62 §J 對照）。
- 留言：設定值域 3（已停用／需審核／自動發布）；狀態值域 3（已核准／未核准／垃圾郵件）；
  動作 4（核准／標記垃圾／取消垃圾／刪除）。
- 效能報表：Core Web Vitals（LCP<2.5s／INP<200ms／CLS<0.1，P75、75% 頁面達標）；
  **資料延遲 ≤36 小時、保留 90 天**；同組數字出現在佈景主題頁與分析報表（鐵律 7 驗收點）。
