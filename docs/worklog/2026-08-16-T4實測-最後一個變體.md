# 2026-08-16 — T-4 實測：`CANNOT_DELETE_LAST_VARIANT` 到底擋的是什麼

> **背景**：parity 查證發現本尊這個 error code 的**名稱與描述不一致**——
> 名稱是 `CANNOT_DELETE_LAST_VARIANT`（最後一個變體），
> 描述是 `"Cannot delete default variant."`（預設變體）。
> 🔴 **在多變體商品上這是兩件事**：多變體商品根本沒有「預設變體」。
> 只實作其中一種而本尊是另一種，會在多變體商品上放行本該擋的操作
> ——而**單變體測試永遠是綠的**（與鐵律 3 的 exponent=2 假綠同型）。

## 已完成的工作 (Done)

### 結論：**admin UI 從不讓商品到達「零個變體」。三種情境全部成功，一次錯誤都沒有。**

刪到最後一個時，UI **不報錯，而是把商品塌縮回「無選項」形態**
（＝本尊的隱含 Default Title 變體）。`CANNOT_DELETE_LAST_VARIANT` 在 UI 路徑上**從未出現**。

### 三種情境

| # | 情境 | 結果 |
|---|---|---|
| **(a)** | 兩個變體，刪其中一個 | ✅ 成功（T-1 已測：A/B 刪 A，剩 B） |
| **(c)** | **單變體商品，刪那一個** | ✅ **成功**——選項整個消失，商品變回無選項形態 |
| **(b)** | **一次全選、一次刪光** | ✅ **成功**——同上，立刻塌縮 |

### 情境 (c) 的細節（商品剩變體 B 時）

- 唯一的變體**仍然有 checkbox**，UI **不預先禁用**；
- 「⋯ → 刪除子類」**沒有變灰**（實測 `disabled=false`、`opacity=1`、`pointerEvents=auto`）；
- 點下去 ⇒ 暫存，**沒有錯誤**；儲存 ⇒ 成功；
- 重載後：**變體 B 不見了、選項「尺寸」整個消失**，
  頁面出現只有無選項商品才有的**商品層欄位**（價格／存貨單位 SKU／條碼／庫存／運送）。

### 情境 (b) 的細節（顏色＝紅/藍，全選兩個）

- 表頭 checkbox 全選 ⇒「已選取 2 個」；
- 「刪除子類」同樣**黑字可點**（實測未 disabled）；
- 點下去 ⇒ 畫面**立刻**變成商品層單變體形態（價格／比較價格／單價／收取稅金／
  每品項成本／庫存／SKU／條碼／運送），**沒有任何錯誤或警示**；
- 儲存＋重載確認：紅/藍都不見了、選項不見了、商品仍在。

## 尚未完成或需注意的風險 (Pending / TODO)

1. 🔴 **本次測的是 admin UI，不是 `productVariantsBulkDelete` 直呼——兩者不可混為一談。**
   UI 走的很可能是 `productSet` 或 `productOptionsDelete`（因為它把「刪最後一個變體」
   實作成「移除所有選項」），**而不是** `productVariantsBulkDelete`。
   ⇒ 🔴 **本結論證明的是「UI 的行為」，不證明「該 error code 的觸發條件」。**
   T-4 原本的問題（名稱 vs 描述哪個對）**仍未直接回答**，要拿真 Admin API token 打
   `productVariantsBulkDelete` 才能看到 userErrors 原文。
   ⚠️ 測試店 admin 走內部 persisted-query API（`/api/operations/{hash}/{Op}/`），
   不能當公開 Admin API 的 parity 依據（PR #29 假設清單已登記同一件事）。
2. ✅ **但有一個可以直接用的結論**：**我方的 UI 不得把「刪最後一個變體」實作成錯誤**。
   本尊在這條路徑上給的是「塌縮成無選項商品」，不是 userError。
   照 error code 的字面去做一個「至少要留一個變體」的阻擋，**會與本尊的 UI 行為不一致**。
3. 🔴 **這條連帶影響 `docs/specs/63` §B.5 第三列**（「刪光所有選項 ⇒ 保留 position 最小的變體」）。
   本次實測顯示本尊**不是**「保留某一個既有變體」，而是**全部刪掉再回到隱含預設變體**
   ——那顆變體是**新的**還是**沿用其中一個**，UI 看不出來（都顯示為無選項商品）。
   ⚠️ **要區分只能靠 variant id**：拿 Admin API 比對刪除前後的 id。
   🔴 **這一題會直接決定 §B.5 第三列要不要改寫**，而它現在寫的是「保留」。
4. ⚠️ **只在「無庫存、無訂單」的變體上測了 (b)/(c)**。
   T-1 已證明「有訂單的變體」可以刪，但沒測「有訂單的**最後一個**變體」。
5. ⚠️ **測試資料留著**：商品 `9891043115243` 現在是無選項單變體商品，
   訂單 #1006 仍指向那個已刪除的變體 A（T-1 的證據）。
