### 20.3 correction validator

下式驗第九輪 dated correction 的固定七類映射；刪掉 ⑥ 的 mutation 必須被拒絕：

~~~bash
ruby -E UTF-8:UTF-8 <<'RUBY'
path = "docs/worklog/2026-08-21-PR64第九輪Codex驗收修復.md"
text = File.read(path, encoding: "UTF-8")
correction = text[/<!-- 🔴 2026-08-21 第十一輪更正.*?-->/m] or abort "missing correction"
required = [
  "①＝驗收攝取", "②＝producer／consumer", "③＝完成性聲明", "④＝狀態空間",
  "⑤＝fail-open", "⑥＝workflow 本機假綠", "⑦＝Markdown／Windows"
]
validate = lambda do |candidate|
  missing = required.reject { |token| candidate.include?(token) }
  abort "missing fixed 20.2 mapping #{missing.inspect}" unless missing.empty?
end
validate.call(correction)
mutated = correction.sub("⑥＝workflow 本機假綠、", "")
abort "mutation did not alter correction" if mutated == correction
begin
  validate.call(mutated)
rescue SystemExit
  puts "missing-⑥ mutation rejected"
else
  abort "missing-⑥ mutation survived"
end
puts "20.3 correction mapping OK"
RUBY
~~~
