## 已完成的工作 (Done)
- `ThemeEngine::Tags::FormTag` 改為**逐型固定 opening tag**（官方 shopify.dev/docs/api/liquid/tags/form，
  取證 2026-09-02）：每型的 action／預設 id／class／enctype／型別 data-*／型別隱藏欄
  （`product-id`、`guest`、`_method=put`、`return_to`）。型別數可複驗：
  `grep -c 'action: "/' app/liquid/theme_engine/tags.rb`。
- 參數解析：key 允許連字號（`data-*`／`aria-*`／`novalidate`／`style`／`is`），值可為字串字面或
  變數（渲染期求值、nil 不輸出）；位置參數（資源）與 `key:` 參數以「是否帶冒號」區分。
- 主題 `id`／`class` **取代**預設；contact／customer 的 action fragment 跟隨生效 id；
  屬性序與隱藏欄自閉形照真店 hoko.vip（Ella 7.2.0）2026-09-02 首頁／`/pages/contact` 逐字。
- `ThemeEngine::FormDrop` 依型別宣告屬性（官方 objects/form 的「Exclusive to … forms」對映）：
  `password_needed`＝true（customer_login）、`posted_successfully?` 純 GET＝false
  （customer_address＝true）、`errors`＝nil；宣告欄位不再計 conformance miss。
- spec `spec/liquid/form_tag_spec.rb` F1–F8（含 Ella／Kalles／Minimog 真主題片段）：
  `bundle exec rspec spec/liquid/form_tag_spec.rb` 全綠。
- 突變輪（鐵律 20.2⑤，腳本在 session scratchpad `mutate_form.py`，每次 `git checkout --` 還原）：
  M1 拔 `password_needed` ⇒ F1 紅；M2 `posted_successfully?` 寫死 true ⇒ F4 紅；
  M3 參數只吃引號字串 ⇒ F3＋F7 紅；M4 拔型別欄位宣告 ⇒ F2 紅。
