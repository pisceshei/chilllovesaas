## 尚未完成或需注意的風險 (Pending / TODO)

- 🔴 缺口成因：admin SPA 是宣告式、**恆送全樹**（含未編輯的既有譯文）；ML-2 的原 spec 只測了「改來源文字且**不送** translations」，漏掉實際前端形態的組合，導致單元測試全綠但線上不標過期。教訓：**宣告式 API 的測試必須照前端真實 payload 形態出題**，不能只測最小輸入。
- `value_source`／`review_required` 同樣只在改寫時重設——機翻譯文（ML-5）被原值回送時不會被誤標成 human，這是刻意行為。
