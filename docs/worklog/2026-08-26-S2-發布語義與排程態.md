## 已完成的工作 (Done)

### 1. 🔴 本尊兩個讀出投影，同名布林在一個狀態上答案相反

官方原文逐字（取證 2026-08-26）：

| 投影 | `isPublished` 的官方描述關鍵句 |
|---|---|
| `ResourcePublication`（V1） | `Also returns true if the resource publication is scheduled to be published.` |
| `ResourcePublicationV2` | `If false, then the resource publication is staged to be published to the publication.` |

⇒ **已排程未到點**：V1 回 **true**、V2 回 **false**。
完全未發布：V1 回 false，而 V2 **根本沒有這一列**（官方逐字
`an instance of ResourcePublicationV2 can't be unpublished`）。

**我方只實作 V2**，理由逐條在 dev doc §2。關鍵一條：`resourcePublicationsV2`
**有** `onlyPublished`（default true）**和** `catalogType` ⇒ V2 是 V1 的功能超集，
只出 V2 沒有缺口（本輪定點複驗 `Publishable` interface 頁）。

### 2. 🔴 修掉 S1 交付的一個真 bug（C-10）

S1 的 `PublicationType#published_resource_count` 是 `object.resource_publications.count`
——**完全不看 `published_at`**。S1 當下無害（生產上 `published_at` 恆為過去），
但**排程一存在就是錯值**：排到下個月的商品會被算成「已發布」。

拆成兩個語義各自明確的欄位，各走 model scope（唯一產生處）：
`publishedResourceCount`（已到點）與 `stagedResourceCount`（已排程未到點）。
`published_at IS NULL` 的列**兩個都不算**。

### 3. 排程態是強制測試維度（與鐵律 3 的 zero-decimal 陷阱同型）

兩種投影的分歧**只在「已排程未到點」這一格顯現** ⇒ **沒有排程 fixture 的測試矩陣
會 100% 全綠，而實作可以完全做錯**。

研究階段實查（HEAD `b399d79`）：`Collection.with_member_counts` 組與
`ProductVariant.purchasable_on` 組各自**零個**未來 `published_at` 的格子；
`spec/requests/publication_lifecycle_spec.rb` 的 `from_now` 命中數為 **0**。

補上 `spec/models/scheduled_publishing_spec.rb`（七組判準，複驗集合：
`grep -n "^  describe " spec/models/scheduled_publishing_spec.rb`）與
`spec/requests/resource_publication_projection_spec.rb`。

### 5. 變體排程守衛改引 `config/limits.yml`（鐵律 6）

原本硬編 `publishable_type == "ProductVariant"`，而正典是
`sales_channels.future_publishing_unsupported: [variant, shop_channel]`——兩份清單。
⚠️ 該正典鍵在此之前是**零消費者**（正典宣告與實作不符，鐵律 19）；本方法是它的第一個消費者。

🔴 對照用**明確的常數表**不用字串魔法：`ProductVariant.underscore` 是 `product_variant`
不是 `variant`，靠推導會靜默對不上而且沒有任何測試會紅。

### 6. 後台實測（`docs/research/82` §12 新增）

- 🔴 **逐商品 modal 顯示目前狀態，批次 modal 一律全部未勾**——同一件事兩種語義，
  我方實作不得做成同一個元件（§12.2）
- 🔴 **`Schedule publishing` 圖示只出現在 Online Store 那一列**，POS／Shop 都沒有（§12.3）
- 排程彈層：日期 ＋ 時間 ＋ **內嵌 `GMT+8` 徽章**、**過去日期全部禁用**、
  `Remove schedule` 是一等操作
- Agentic 是**唯讀的資格審核態**（`Pending` 徽章），不是發布開關（§12.4）
- Catalog 成員是逐商品 toggle，`Status` 篩選恰 `Active`／`Draft`／`Archived`（§12.5）
