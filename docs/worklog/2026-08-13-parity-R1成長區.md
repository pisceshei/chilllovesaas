## 修改的檔案與核心邏輯 (Changes)

- `docs/design/chilllove-admin-v2.html`（約 -70/+180 行，四個函式＋FORMSEL＋DOCS 區塊）、`docs/specs/71`（§E/§F）。
- **為什麼刪「內容編輯器」不是刪功能**：受眾/主旨/模板屬 Shopify Email app 的 activity 層；campaign 層只是
  歸因容器——原型把兩層壓成一層，正是「同名不同物」形態。移除＝歸位，activity 編輯屬行銷應用程式範圍（R13）。
- **為什麼歸因頁不掛 save bar**：本尊參數全部 URL query 化（attributionModel=…），報表參數不是店家設定；
  掛 save bar 會教實作者把模型存進 DB——那會讓「同一連結兩人開啟看到不同數字」。
- **追溯註釋**：三個改寫點各留原文摘要＋雙源出處＋🔴 防回退（表單化/回溯窗/內容編輯器三個舊形態不得回流）。
