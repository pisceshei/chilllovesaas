### 2. 四支腳本缺執行位元

`git ls-files -s scripts/` 實測：10 支腳本全部帶 shebang，其中 **4 支是 `100644`**——
`check-baseline-raise.py`／`check-money-boundary.rb`／`test-lint-rules.py`／`test-money-rules.rb`。
CI 用 `ruby`／`python3` 前綴呼叫故無功能影響，但 `./scripts/<檔>` 直跑會 Permission denied。

### 3. 🔴 擴大執行位元閘門（本 PR 的重點，不只是補那 4 個位元）

原本的 `Verify bin/ scripts are executable` 只掃 `bin/` 與 **`scripts/*.sh`**
⇒ `scripts/*.rb`／`*.py` 從來不在網內。**這道閘門擋不住它自己所在目錄裡的同一種錯**，
所以那 4 支才能一路綠燈存在。

新判準＝**帶 shebang 就必須可執行**：帶 shebang 是宣告「我可以直接跑」，
宣告了卻沒有執行位元就是自相矛盾。無 shebang 的檔（資料、fixture）不受影響。

```bash
bad=$(
  git ls-files -s bin/ | awk '$1 != "100755" { print $4 }'
  git ls-files -s scripts/ | awk '$1 != "100755" { print $4 }' | while read -r f; do
    if head -c 2 "$f" | grep -q '#!'; then echo "$f"; fi
  done
)
```

該步驟在 `test` 與 `quality` 兩個 job 各有一份，**兩份都改**（否則兩個 job 的判準會分岔）。

**自測**（新閘門的正反向都跑過，不是只跑正向）：
- 正向：補完 4 個位元後 → **無違規**。
- 反向：把 `test-money-rules.rb` 用 `git update-index --chmod=-x` 改回 100644 →
  **抓到 `scripts/test-money-rules.rb`**。已還原。
- `ci.yml` 仍可解析；`test-money-rules.rb`／`check-money-boundary.rb` 重跑全綠；
  `rubocop` no offenses。

### 4. 驗收後修正（PR #35 第 1 輪 Codex review 兩條，皆成立）

**P2｜路徑含空白會被靜默漏掉。** `git ls-files -s` 的格式是
`<mode> <sha> <stage>\t<path>`——**路徑在 TAB 之後**，且路徑本身可以含空白。
初版沿用原本的 `awk '{ print $4 }'`（以空白切欄）⇒ `scripts/a script.sh` 被截成 `scripts/a`，
下面的 `head` 讀不到檔案、條件為假 ⇒ **該檔靜默漏掉**。

實測（建一個 `scripts/a script.sh`、故意設成 100644）：

| 寫法 | 取到的路徑 | 結果 |
|---|---|---|
| `awk '$1 != "100755" { print $4 }'` | `scripts/a` | **漏掉**（head 讀不到） |
| `awk -F'\t' 'substr($1,1,6) != "100755" { print $2 }'` | `scripts/a script.sh` | **抓到** |

⇒ 改用 TAB 當分隔符，並把 `read -r f` 改成 `IFS= read -r f`（保留前後空白）。測試檔已刪除。

🔴 這條**原本的寫法也有**（不是本 PR 引入的），但本 PR 把它從「只掃 `*.sh`」擴大到
「掃整個 `scripts/`」之後，命中面積變大 ⇒ 順手修掉才算數。

**P1｜`AGENTS.md` 沒跟上，文件與機制分岔。** 該節仍寫「提交前檢查
`git ls-files -s bin/ scripts/*.sh`」並說「**不要依賴** CI」——
讀文件的人會以為 `.rb`／`.py` 不受管，而 CI 已經改成 shebang 判準。
⇒ 改寫該節：寫出新規則、附與 CI **逐字一致**的檢查指令，並加一條
「改這條規則時 `ci.yml` 兩份與本節必須同步改」。

🔴 這正是本專案反覆出現的形態——**機制與規則各跑各的，而 CI 是照機制跑的那一份**
（`CLAUDE.md` 鐵律 2 的白名單註釋裡有同型教訓）。
