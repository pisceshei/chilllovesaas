### 為什麼分層——舊結構表達不了實測

本尊在 **12px 這一個字級上同時有三種字重**（表格儲存格 450／欄位標題鈕與 badge 與按鈕標籤
550／`heading-small` 600），13px 上同樣有三種。我方 `--t-xs ↔ --fw-xs` 的一對一配對只能
表達其中一種。

**而我方自己的程式碼早就在違反它**——導出見文末：
`--t-xs` 消費 **265** 處、`--fw-xs` **1** 處、`--fw-sm` **0** 處 ⇒ 配對只活在註釋裡。

### 🔴 而且不能靠改 size token 的值來對齊

`--t-lg`（16px）同時是 SERP 模擬標題（**模仿 Google，不是 admin 元素**）、modal 標題、
setup 卡 h4、帳目數字、統計數字、logo 預覽。本尊卡片標題是 13px，
**但把 `--t-lg` 改成 13 會一起縮掉 SERP 模擬**，而那個 16px 本來就是對的。

⇒ 必須由**元件指到角色**，不是指到尺寸。

### 三層

| 層 | 內容 | 本包 |
|---|---|---|
| **L1 原語** | 字級 13 階（沿用本尊編號 `--t-275`…`--t-1000`）／行高 8 階（**獨立編號**）／字重 4 抽象階／字距 4 抽象階 | 新增 |
| **L2 角色階** | **16 個**，與本尊 1:1；**軸集也 1:1，沒有的軸不建 token** | 新增 |
| **L3 過渡階** | 舊 `--t-{2xs..3xl}`，值指回 L1 | 保留，逐元件遷移＝包 C-2 |

L2 四種形狀：unary 2／size+lh+ls（無 weight）4／size+lh+weight（無 ls）4／四軸齊 6。

### 修掉四個值域外字重

| token | 前 | 後 | 消費 | 依據 |
|---|---|---|---:|---|
| `--fw-control` | 500 | **550** | **14** | 本尊 `.button{font-weight:var(--p-font-weight-button-label,550)}`；枚舉全部 `.button*` 字型規則**只有這一條** |
| `--fw-md` | 500 | **550** | 3 | 變體表 `thead th`／`tbody th`／刪檔警告；本尊 `.Polaris-Table-TableHeadingCell` = 550 |
| `--fw-xs` | 500 | **550** | 1 | `.idx th` 表格欄位標題，同上 |
| `--fw-xl` | 500 | **600** | 1 | 原型 `.modal-head`；本尊 modal 標題走 `display-small` = 600 |

**複驗**：25 顆字重 token 解析後全部落在 {450,550,600,650}，**值域外 0 顆**（換值前 4 顆）。

```python
# A) L3 過渡階的「配對只活在註釋裡」——字級 vs 配對字重的消費數落差
import re, io, collections
cnt = collections.Counter()
for f in ('app/assets/stylesheets/admin.css', 'docs/design/chilllove-admin-v2.html'):
    for m in re.findall(r'var\((--(?:t|lh|fw)-[a-z0-9]+)\)', io.open(f, encoding='utf-8').read()):
        cnt[m] += 1
for k in ('--t-2xs', '--t-xs', '--t-sm', '--t-md', '--t-lg', '--t-xl', '--t-2xl', '--t-3xl',
          '--fw-2xs', '--fw-xs', '--fw-sm', '--fw-md', '--fw-lg', '--fw-xl'):
    print(f'{k:<10}{cnt[k]}')
# 期望（本包後不變，因為只改值不改消費）：--t-xs 265、--fw-xs 1、--fw-sm 0
```

```python
# B) 三軸的值域對帳 —— 🔴 附 canary，證明解析鏈真的在跑
import re, io
c = re.sub(r'/\*.*?\*/', '', io.open('app/assets/tokens.css', encoding='utf-8').read(), flags=re.S)
raw = {k: v.strip() for k, v in re.findall(r'(--[a-z0-9-]+)\s*:\s*([^;}\n]+)', c)}

def rez(v, d=0):
    m = re.fullmatch(r'var\((--[a-z0-9-]+)\)', v.strip())
    return rez(raw[m.group(1)], d + 1) if (m and d < 8 and m.group(1) in raw) else v.strip()

assert rez(raw['--fw-control']) == '550', 'canary 失敗：解析鏈沒在跑，下面的結果不可信'

W = {'450', '550', '600', '650'}
SZ = {'11px','12px','13px','14px','16px','18px','20px','22px','24px','30px','32px','36px','40px'}
LH = {'12px','16px','20px','24px','28px','32px','40px','48px'}

wk = [k for k in raw if k.startswith('--fw-') or k.endswith('-fw')]
sk = [k for k in raw if k.startswith('--t-') or k.endswith('-size')]
lk = [k for k in raw if k.startswith('--lh-') or k.endswith('-lh')]
print('字重 token', len(wk), '域外', sorted({rez(raw[k]) for k in wk} - W))
print('字級相異值', sorted({rez(raw[k]) for k in sk}), '域外', sorted({rez(raw[k]) for k in sk} - SZ))
print('行高相異值', sorted({rez(raw[k]) for k in lk}), '域外', sorted({rez(raw[k]) for k in lk} - LH))
roles = {re.match(r'(--type-[a-z-]+?)-(size|lh|fw|ls)$', k).group(1)
         for k in raw if re.match(r'--type-[a-z-]+-(size|lh|fw|ls)$', k)}
print('角色階', len(roles))
# 期望：字重 25 域外 []；字級域外 []；行高域外 ['14px']（--lh-2xs，我方自有）；角色階 16
```
