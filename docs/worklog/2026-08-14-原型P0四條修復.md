### 三、C-01 分群求值器

- 原本是三條 regex，**都不中就回 `CUSTOMERS.length`（全部顧客）**——不是佔位符，**是錯誤數字**。
- 新增 `segMatch()`：支援 `field OP value` 以 AND／OR 連接，
  欄位表 `SEG_FIELDS` 逐一列舉，🔴 **無法求值時回 `ok:false` 而非全部顧客**，
  UI 顯示「—」＋ caution banner 說明原因。
- 🔴 **人數與名單改為同源**（同一次 `segMatch()`）——原本名單是 `CUSTOMERS.slice(0,n)`
  「拿前 n 筆當成員」，於是出現「數字對、名單錯」（鐵律 7）。
- 🔴 **順帶修正單位邊界（鐵律 3）**：查詢字面量 `amount_spent > 5000` 是主單位，
  `c.spent` 是 cents。原本直接比較等於在問「> HK$50」。

### 四、PR-01 商品批次選取整鏈

- thead 全選框無 handler、列身 checkbox 無 handler、無 bulkbar、匯出「已選取的商品」是空指向。
- 補 `prodToggleAll`／`prodBulk`／`prodSelected` ＋ bulkbar（5 個批次操作）＋ indeterminate 半選態。
- 🔴 **class 用 `prodcb` 而非訂單頁的 `rowcb`**：本原型是 SPA、所有頁面同時在 DOM，
  共用 class 會讓 `bulk()` 把訂單列一起數進來。選擇器一律限定 `#prodTable` 內。
- 匯出：無選取時**該選項不出現**（而不是留一個保證空的範圍），有選取時帶筆數並成為預設；
  `prodExportRun()` 真的讀範圍並回報實際筆數。
