## 已完成的工作 (Done)

`claude-review.yml` 原本對 `--effort` 的註釋寫：

> `--effort max`：CLI **五級**推理強度 low/medium/high/xhigh/max，**max＝最高**。

兩處與官方不符，`33743a5` 修正：

1. **是六級不是五級。** 官方 CLI reference 的 allowed values 逐字為
   `low, medium, high, xhigh, max, or ultracode`。
2. 🔴 **`max` 不是「最高」那麼簡單。** 官方對 `ultracode` 的描述是
   「starts the session at `xhigh` effort」——它的**起點比 max 低**，
   所以它不是「比 max 更高的第六級」，而是**另一個維度**（深度換廣度）。
   把六個值排成一條直線、宣稱 max 在頂端，是把兩種不同的東西放進同一個量尺。
   ⚠️ 官方那一頁**沒有**把 max 描述成最高級——「max＝最高」是我方加上去的。

另記：`ultracode` 需要 Claude Code **v2.1.203+**，而 action 內建 CLI 的版號無從得知
⇒ 與模型那一行同樣的理由，不去用它。
