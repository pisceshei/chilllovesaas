## 尚未完成或需注意的風險 (Pending / TODO)
- `select`／`radio` 官方句是「第一個 option」——本包取 options 陣列第一個帶 `value` 的項；
  官方是否跳過 `group` 分組項＝未取得（三套主題的 options 都是平鋪形）。
- `range` 官方明載 default 必填（缺＝主題錯誤），本包不補；`number`／`text` 無 default ⇒ 官方回 nil／空，維持。
- `color_scheme` 在無 `color_scheme_group` 的主題（無群組語境）維持值原樣，官方此情境語義＝未取得。
- preclassify 的 theme-quirk 類（主題讀了自己沒宣告的 setting）本來就不是引擎缺口，不在本包。
