# 2026-09-03 主題編輯器 E3：左樹依本尊重做（D79）

## 已完成的工作 (Done)

- 依 `docs/research/100-theme-editor-live-teardown.md` §2／§2.1／§2.2／§2.3／§4 重做左欄 sections 樹：
  - 分帶：section group 依 `layout/theme.liquid` 中 `{% sections %}` 相對 `content_for_layout` 的位置排在 Template 帶
    上方（header 類）或下方（footer 類）；小標＝群組 JSON `name`；footer 類的 "⊕ Add section" 在列之上。
  - 列解剖：chevron（有子項或可加子項才顯示）／type icon（hover 換成 drag handle）／名稱（JSON `name` ?? schema name）
    ＋block 摘要（第一個文字設定，斜體灰）／hover 動作垃圾桶、眼睛；隱藏列灰字＋眼睛常駐；選中列實心底。
  - 展開後第一個子列 "⊕ Add block"；theme block 巢狀（容器依其 `blocks` 接受清單列子型別，`@theme`＝全部；最深 8 層）。
  - 右鍵選單：Paste（灰）／Rename／Hide⇄Show（鍵帽 Ctrl Shift H）／Add section before／after（section 列）／Edit code。
  - Rename：右欄標題就地輸入，Enter／blur 寫進模板 JSON `name`，Esc 取消，空值清除。
  - 鍵盤：Shift+↑↓ 沿可視列移動（收合子層跳過）、Shift+Enter 焦點進右欄第一個控件、Ctrl+Shift+O／P 展開／收合全部；
    Esc 在改名中先取消改名。快捷鍵仍只有 `editorShortcuts.ts` 一張表。
  - 每帶各自的 Add section：候選依 `enabled_on`／`disabled_on`（Template 帶對模板型、群組帶對群組 `type`）過濾，
    同帶同型達 `limit` 灰化並標 "(n/limit)"；右鍵 before／after 插到指定位置。
  - 資源模板（product／collection／page／blog／article）的 Preview 列：popover 搜尋＋清單 → `previewPath`；命中者鉛筆
    連到後台編輯頁。
  - URL：`block=` 改為 `__` 串接的路徑；還原時自動展開祖先。
  - static block（Ella `templates/product.json` 的 media-gallery／product-details／sticky-atc：只在 `blocks` map、不在
    `block_order`）照樣列在樹上：鎖 icon、不可拖、無垃圾桶、Shift+⌫ 不刪、可選取／改設定／隱藏，save 不動 `block_order`。
- 後端 `ThemeType`：`sectionGroups` 加 `label`／`type`／`position`；`sectionSchemas` 加 `enabled_on`／`disabled_on`／
  `limit`；新欄 `themeBlocks`（`blocks/*.liquid` 的 type／name／settings／可接受子型別）。
- 五語系 i18n：新增樹相關鍵；移除 E2 留下的無消費者舊鍵（`editor.selectHint`／`saveComing`／`headerBand`／`footerBand`／
  `blockUp`／`blockDown`／`moveUp`／`moveDown`／`sectionType`／`mobilePreview`）；新鍵 `editor.staticBlock`。
- 外部語義補證：`limit`／`max_blocks`／`enabled_on`／`disabled_on`／`["*"]` 逐字取自 Shopify section schema 官方頁
  （取證 2026-09-03，引文在 `docs/dev/e3-theme-editor-sections-tree.md` 規格出處）。
