# 2026-09-03 主題編輯器 E6：預覽互動依本尊重做（D79）

## 已完成的工作 (Done)

- 預覽橋抽成 `app/assets/javascripts/editor-bridge.js`（引擎載入時讀進 `EDITOR_BRIDGE_JS`；vitest 以 `?raw` 載入在 jsdom 執行
  同一份）。依 `docs/research/100` §5／§9.5 實作：
  - inspector 開時 hover ⇒ 藍框＋左上 chip（顯示名由父頁 `cl:names` 推送，同左樹）；section 上下邊界「+」（tooltip 跟 admin
    語系）⇒ `cl:insert {id, position}` ⇒ 父頁開區段 picker 於該位置並在左樹標插入線。
  - 點選 ⇒ `cl:select`；父頁回推 `cl:highlight` ⇒ 選中框＋捲到＋浮動工具列（Duplicate／Hide／Remove ⇒ `cl:op` 帶 blockId）＋
    派 `shopify:section:select`／`shopify:block:select`（前者派 deselect）。
  - 預覽內右鍵 ⇒ `cl:contextmenu {id, blockId, x, y}` ⇒ 父頁以 iframe 座標開左樹同款選單（`SectionsTree.openMenuAt`）。
  - `cl:inspector` 關 ⇒ 全部覆疊隱藏、hover／右鍵不作用、派 `shopify:inspector:deactivate`；開 ⇒ activate。
  - `cl:replace` ⇒ 派 `shopify:section:unload`／`load`；選中段被換時選中框跟到新元素。
  - 站內連結攔截（`cl:navigate`）沿用；異 origin 訊息忽略。
- 引擎：`Shopify.designMode` 改官方語義——公開頁不輸出（undefined），design_mode 才 `true`。
- 頁面：`cl:op` 支援 blockId 與 `hide`；`cl:names`（含工具列文字）於 `bands` 變動與 iframe `onLoad` 推送（連同 `cl:inspector`）。
- E5b 併入：`Popover` 新 `edgeRef`，section／block picker 貼左欄卡片右緣（本尊形態，100 §8.1）。
