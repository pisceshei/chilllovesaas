# 2026-08-28 · D56 決定 A：語義色換成本尊值

三方研究（倉庫現況 × live 量測 × Polaris 源碼結構）的第二個落地包（第一個＝D55 欄寬）。

## 已完成的工作 (Done)

### 根因：不是色值偏差，是**槽位缺失導致的模型塌縮**

我方每族五槽（surface／fill／border／icon／text），**沒有「填色上的前景色」**
⇒ 消費端只能硬編白字（原型 `.b-fill-*` 五處 `color: var(--text-inverse)`）
⇒ fill 被反推成必須夠深
⇒ 產生器把每個色相壓暗到白字剛好過 4.5 就停。

**指紋**：五族 fill 亮度全擠在 **0.166–0.177**（跨度 0.010），本尊是 **0.125–0.779**（跨度 0.654）。

### 換值統計（導出見文末）

| 類 | 顆數 |
|---|---:|
| 有本尊對應、值不同 ⇒ 換 | **52** |
| 有本尊對應、值已相同 | **0** |
| 本尊無此槽 ＋ 我方零消費 ⇒ 刪 | **25** |
| 本尊有、我方缺 ⇒ 增 | **10** |

77 − 25 + 10 = **62 顆**。

換值前 77 顆中**只有 22 顆被消費**（全在原型），**55 顆是死 token（71%）**；
換值後 62 顆中 **27 顆被消費**（+5 ＝ `.b-fill-*` 新引用的 `on-fill`），死 **35 顆（56%）**。
`admin.css` 不直接用 `--sem-*`，走別名層（`--success`／`--critical-bg` 等，29 處）。

### 🔴 fill 與 on-fill 必須成對換（本包最關鍵的論證）

| 族 | 換值前（舊 fill ＋ 白字） | **只換 fill**（新 fill ＋ 白字） | 本包（新 fill ＋ on-fill） |
|---|---:|---:|---:|
| success | 4.63 | 5.25 | 5.20 |
| critical | 4.85 | 6.00 | 5.81 |
| **warning** | 4.80 | 🔴 **1.73** | 9.87 |
| **caution** | 4.82 | 🔴 **1.27** | 10.82 |
| **info** | 4.74 | 🔴 **1.66** | 10.01 |

**只換 fill ⇒ 3/5 族直接 AA 失敗**（最低 1.27）。成對換 ⇒ 5/5 通過（最低 5.20）。

⇒ 這不是「顏色不像」，是無障礙失敗。故原型 `.b-fill-*` 五處與 fill 換值**同一提交**。

### 我方實際產生的每一組（底,前景）配對，逐一驗過

掃「同一條規則同時設 background 與 color 且至少一端是 `--sem-*`」，解析 `var()` 鏈後算 WCAG：
**12 組，0 組未達 AA 4.5**（最低 5.20，最高 10.82）。

### 刪除的 25 顆

5 族 × `border-hover`／`border-active`／`icon-hover`／`icon-active`（20）、
`caution-text-hover`／`-active`、`info-text-active`（3）、
`critical-button-fill`／`-button-gradient-fill`（2）。

- 本尊只有 **`highlight`** 族有 icon／border 的 hover／active，其餘六族該格全空。
- 那兩顆按鈕 token 與 `--sem-critical-fill` 重複：本尊 primary destructive ＝
  `bg-fill-critical` ＋ `text-critical-on-bg-fill`；secondary ＝ `button-bg-fill-critical`
  **`#fff`** ＋ `text-critical`。我方原值（紅底 `#c11f35` ＋漸層）是**相反模型**且零消費。

### 照實複製本尊自己的三處不一致

①`info-text-hover` == `info-text`（hover 無變化）②`border-caution` == `fill-secondary-caution`
（同時用會讓邊框隱形——本尊實際不會發生，11169 條規則掃描交集為空）
③`icon` 在同族 surface 上的對比逐族為 info 3.05／warning 3.06／caution 3.29／critical 3.86／
ai 4.35／success 4.69／highlight 5.48，在更暗的 `fill-secondary` 上是 2.49–4.98
（⇒ 七族中五族在 WCAG 1.4.11 的 3:1 線上下擦邊；**icon 必須伴隨文字**，不得單獨承載語義）。
**修正它們就不是 1:1**，故照抄並在 token 表原處標明。

# A) --sem-* 的定義／消費／死 token 對帳
import re, io
c = re.sub(r'/\*.*?\*/', '', io.open('app/assets/tokens.css', encoding='utf-8').read(), flags=re.S)
defined = set(re.findall(r'(--sem-[a-z-]+)\s*:', c))
used = set()
for f in ('app/assets/stylesheets/admin.css', 'docs/design/chilllove-admin-v2.html'):
    used |= set(re.findall(r'var\((--sem-[a-z-]+)\)', io.open(f, encoding='utf-8').read()))
print('定義', len(defined), '消費', len(used), '死', len(defined - used),
      '懸空', len(used - defined))
assert '--sem-warning-fill' in defined, 'canary 失敗：正則抓不到已知存在的 token'
# 換值後期望：定義 62、消費 27、死 35、懸空 0

```python
# B) 我方實際產生的每一組（底,前景）配對的 WCAG 對比
#    🔴 附反事實：同時算「只換 fill 不換前景」會是什麼，證明成對換是必要的。
import re, io
c = re.sub(r'/\*.*?\*/', '', io.open('app/assets/tokens.css', encoding='utf-8').read(), flags=re.S)
raw = {k: v.strip() for k, v in re.findall(r'(--[a-z0-9-]+)\s*:\s*([^;}\n]+)', c)}

def rez(v, d=0):
    m = re.fullmatch(r'var\((--[a-z0-9-]+)\)', v.strip())
    return rez(raw[m.group(1)], d + 1) if (m and d < 6 and m.group(1) in raw) else v.strip()

def lin(x):
    x /= 255
    return x / 12.92 if x <= 0.04045 else ((x + 0.055) / 1.055) ** 2.4

def L(h):
    h = h.lstrip('#')
    if len(h) == 3:
        h = ''.join(ch * 2 for ch in h)
    r, g, b = (int(h[i:i + 2], 16) for i in (0, 2, 4))
    return .2126 * lin(r) + .7152 * lin(g) + .0722 * lin(b)

def cr(a, b):
    la, lb = L(a), L(b)
    hi, lo = max(la, lb), min(la, lb)
    return (hi + .05) / (lo + .05)

fails = 0
for f in ('docs/design/chilllove-admin-v2.html', 'app/assets/stylesheets/admin.css'):
    txt = io.open(f, encoding='utf-8').read()
    for m in re.finditer(r'\{([^{}]*)\}', txt):
        body = m.group(1)
        bg = re.search(r'background(?:-color)?\s*:\s*(var\(--[a-z0-9-]+\)|#[0-9a-fA-F]{3,6})', body)
        fg = re.search(r'(?<!-)color\s*:\s*(var\(--[a-z0-9-]+\)|#[0-9a-fA-F]{3,6})', body)
        if not (bg and fg) or '--sem-' not in bg.group(1) + fg.group(1):
            continue
        b_, g_ = rez(bg.group(1)), rez(fg.group(1))
        if not (b_.startswith('#') and g_.startswith('#')):
            continue
        v = cr(b_, g_)
        if v < 4.5:
            fails += 1
            print('FAIL', bg.group(1), fg.group(1), round(v, 2))
print('未達 AA 4.5 的組數 =', fails)   # 期望 0

# 反事實：只換 fill、前景仍用白字
NEW = {'success': '#047b5d', 'critical': '#c70a24', 'warning': '#ffb800',
       'caution': '#ffe600', 'info': '#91d0ff'}
broken = [k for k, v in NEW.items() if cr(v, '#ffffff') < 4.5]
print('只換 fill 會 AA 失敗的族 =', broken)   # 期望 ['warning', 'caution', 'info']
```
