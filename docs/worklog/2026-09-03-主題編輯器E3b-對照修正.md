# 2026-09-03 主題編輯器 E3b：與本尊並排對照後的修正（D79）

## 已完成的工作 (Done)

- 使用者以本尊編輯器（真店副本 theme 143506604135）與 bt3 demo 店並排截圖點名「左樹排位醜、預覽不一樣、整體 UI 要
  百分百複製」。逐項查實根因後修正：
  - **群組帶漏兩個**：Ella 的 popup-group／general-group 用 `{%- liquid sections 'popup-group' … -%}` 行內形引入，
    `ThemeType#section_groups` 與引擎 `PageRenderer#layout_group_names` 都只認 `{% sections 'x' %}` ⇒ 樹只出三帶、
    `section_id` 端點對這兩組回 404。兩處改為同一正則（兩種語法都認，位置以匹配起點判 before／after）。
  - **`t:names.*` 原鍵外露**：Ella 匯出的 section／block 實例帶 `"name": "t:names.announcement_bar"`（preset 名），
    E3 把實例 `name` 當改名文字直接顯示。新增 bootstrap 欄 `nameTranslations`（只含實際出現的 `t:` 鍵，缺翻譯者不列），
    樹列／面板標題／改名預設值走 `translateName`（缺鍵 fail-open 顯示原鍵）。
  - **佔位插圖**：本尊 `placeholder_svg_tag` 輸出整張插圖（hoko.vip 實測 `<svg class="placeholder-svg"
    preserveAspectRatio="xMidYMin slice" viewBox="0 0 1300 731" fill="none">…`），我方只回 100×100 色塊 ⇒ slideshow
    成一格米色空框、header 沒疊在 hero 上。新增 `ThemeEngine::PlaceholderSvg`（官方名稱表 30 個全部有圖、**我方自繪**、
    class 未給＝`placeholder-svg`、給了逐字用、方形 525.5／寬幅 1300×731）；`payment_type_svg_tag` 保留舊色塊。
  - **demo 店沒有主選單** ⇒ header 空白：`db/seeds.rb` 加 idempotent 的 `main-menu`（Home／Catalog／Contact；本尊新店
    預設，真店編輯器實測顯示 首頁／目錄／聯絡我們）。
  - **左樹 1:1 量測對齊**（本尊分頁可見時截圖，視窗 1573@125% ⇒ 截圖≈1:1 設計 px）：列距 30（列底 28＋上下 1）、
    標籤 14px/20px 450 深色、chevron 16／type icon 16／名稱起點卡左緣 +53、分帶 hairline 滿寬、小標 14px 深色、
    Add section 14px 藍 550 與 type icon 同 x、選中＝淺灰底（**本尊不是藍底**，更正 100 §2.2）、左欄＝灰底上的白卡
    （8px 內縮、圓角 12、hairline 邊、標題列 36 高 16px 半粗）。量測值登記於 `docs/research/100` §8.1。
- 外部語義：`placeholder_svg_tag` 官方名稱表（shopify.dev，取證 2026-09-03）與 Polaris token 值（polaris-tokens npm
  CSS，取證 2026-09-03）進 `docs/dev/external-facts.md` §F5／§F6。
