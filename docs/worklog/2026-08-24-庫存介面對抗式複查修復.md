### 兩個「看起來沒問題」的坑（都讓測試紅了才發現）

1. 🔴 **`.squish` ＋ SQL 行內註釋 `--` ＝ 吃掉後面整條 SQL**。
   我在 `history_query.rb` 的 heredoc 裡加了 `-- 註釋`，而那段 SQL 走 `.squish`
   把換行壓成空白 ⇒ `WHERE`／`ORDER BY`／`LIMIT` **全部變成註釋的一部分**。
   查詢照樣「成功」，只是語義全變（期後值順序反了、保留窗失效），三條 spec 紅。
   ⇒ 註釋一律寫在 heredoc 外面；真要註在 SQL 裡只能用 `/* */`。
2. 🔴 **`private` 放在 GraphQL field 解析方法之前，那個欄位就在執行期消失**。
   我把 `staff_emails` 連同 `private` 插在 `created_by` 之後、`changes` 之前，
   graphql-ruby 找不到 `changes`（"which did not exist"），三條 spec 紅。
