**先前登記的「1280 不可得」原因是錯的**：

| | 先前解釋 | 本輪實測 |
|---|---|---|
| `screenX` | −32000（離屏、渲染面凍結） | **0** |
| `resize_window` | 回報成功 | 一樣回報成功 |
| `innerWidth` | 不變 | **一樣不變（2560）** |

⇒ **不是離屏，是 resize 本身不生效。** 原歸因作廢。

### ④ 三寬度驗證抓到的分歧（本輪只有這一項；量測範圍＝原型首頁的 8 個元件 × 3 寬度）

390 的 `h1` 是 **17.94** 不是 18。成因是**既有規則**：

```
@media (max-width:47.9975em){ html{font-size:var(--t-md)} }           /* 13 → 14 */
@media (max-width:47.9975em){ h1{font-size:clamp(17px,4.6vw,20px)} }  /* 390×4.6vw = 17.94 */
```

**決定性證據**：同一個 iframe 內，字面 `18px`／`var(--type-display-sm-size)`／inline 強制 18px
**三個探針全部渲染成 18px** ⇒ token 解析正確，是那條 clamp 蓋過角色階。

🔴 **那條規則對不對＝未取得**（見下）。**本輪不動它。**
