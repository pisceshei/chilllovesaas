## 🔴 本輪自己寫出一個會切壞檔案的 bug（閘門抓到）

第一次批次改 `--text-on-brand` 時我這樣寫：

```text
# ⚠️ 這是**錯誤示範的片段**，不是可執行命令（本檔文末的導出命令才是）
for m in re.finditer(r'\{([^{}]*)\}', s):
    ...
    s = s[:m.start(1)] + newbody + s[m.end(1):]   # 🔴 在迭代中改 s
```

`re.finditer` 的 match 偏移是對**舊字串**算的，而
`var(--text-inverse)`(19) → `var(--text-on-brand)`(20) **每次長 1 字元**
⇒ 第 N 次替換時偏移已漂移 N−1，**切掉了選擇器的尾字元與左大括號**：

| 漂移 | 損害 |
|---:|---|
| 0 | `.avatar{` ✅ 完好 |
| 1 | `.ai-badge{` → `.ai-badgewidth`（吃掉 `{`） |
| 2 | `.ai-send{` → `.ai-senwidth`（吃掉 `d{`） |
| 3 | `.annot-bar{` → `.annot-bposition`（吃掉 `ar{`） |

`lint-prototype.py` 以「`<style>` 大括號不平衡：{=1049 }=1053」抓到。

✅ **處置**：`git checkout` 還原原型後**整批重做，全部改用字串錨定**
（`assert s.count(old) == 1` 再 `replace`），不用任何偏移改寫。重做後 ERROR 回到 0。

🔴 **固定處理**：批次改檔一律用「錨定字串 ＋ 斷言命中次數」，
**不得在 `finditer` 迭代中修改被迭代的字串**。若非用偏移不可，
要麼由後往前替換，要麼一次性重建整份字串。

```python
# A) 20 顆中性 token 的值與飽和度 —— 🔴 附 canary
import re, io, colorsys
c = re.sub(r'/\*.*?\*/', '', io.open('app/assets/tokens.css', encoding='utf-8').read(), flags=re.S)
cur = {k: v.strip() for k, v in re.findall(r'(--[a-z0-9-]+)\s*:\s*([^;}\n]+)', c)}
EXP = {'--text': '#303030', '--text-2': '#616161', '--text-3': '#616161',
       '--brand': '#303030', '--brand-hover': '#1a1a1a', '--surface-2': '#f7f7f7',
       '--surface-3': '#f3f3f3', '--border': '#e3e3e3', '--border-2': '#ebebeb',
       '--border-strong': '#ccc', '--border-hover': '#616161', '--surface-hover': '#f1f1f1',
       '--surface-row-hover': '#f7f7f7', '--surface-selected': '#f1f1f1',
       '--surface-sunken': '#e3e3e3', '--scrim': '#000000b5', '--surface-inverse': '#1a1a1a',
       '--text-inverse': '#e3e3e3', '--text-on-brand': '#fff', '--link': '#005bd3'}
assert '--text' in cur, 'canary 失敗：連 --text 都沒解析到，下面的結果不可信'
bad = {k: (cur.get(k), v) for k, v in EXP.items() if cur.get(k) != v}
print('不相符：', bad or '無')

def sat(h):
    h = h.lstrip('#')
    if len(h) == 3:
        h = ''.join(x * 2 for x in h)
    if len(h) == 8:
        h = h[:6]
    r, g, b = [int(h[i:i + 2], 16) / 255 for i in (0, 2, 4)]
    return colorsys.rgb_to_hsv(r, g, b)[1] * 100

neutral = [k for k in EXP if k != '--link']
print('中性階飽和度最大值', round(max(sat(cur[k]) for k in neutral), 1))   # 期望 0.0
```

```python
# B) --text-inverse 的消費點是否全在深中性面板上
import re, io
tot = bad = 0
for f in ('app/assets/stylesheets/admin.css', 'docs/design/chilllove-admin-v2.html'):
    s = io.open(f, encoding='utf-8').read()
    for m in re.finditer(r'\{([^{}]*)\}', s):
        b = m.group(1)
        if 'var(--text-inverse)' not in b:
            continue
        tot += 1
        bg = re.search(r'background\s*:\s*([^;]+)', b)
        v = bg.group(1).strip() if bg else '(繼承)'
        if not (('surface-inverse' in v) or v.startswith('rgba(') or v == '(繼承)'):
            bad += 1
            print('非深中性面板:', v[:60])
tb = sum(len(re.findall(r'var\(--text-on-brand\)', io.open(f, encoding='utf-8').read()))
         for f in ('app/assets/stylesheets/admin.css', 'docs/design/chilllove-admin-v2.html'))
print('--text-inverse', tot, '處／非深中性面板', bad, '／--text-on-brand', tb)
# 期望：12 處／0／10
```
