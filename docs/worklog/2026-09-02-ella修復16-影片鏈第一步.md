- 6 軸艦隊覆蓋軸「影片/3D 媒體鏈全 stub」的 filter 層收口（官方取證

  input-settings#video_url）：
- **VideoUrlDrop**（video_url setting 值物件）：官方＝「a string that
  contains the entered URL」＋ `id`/`type`（youtube/vimeo）、空 ⇒ nil。
  🔴 用 Drop 不用 String 子類——Liquid 對非 Drop 走 `[]`，`String#[]("id")`
  是子字串搜尋，`url['id']` 會回 `"id"` 假值（VC1 殺手格）。
  解析支援 watch/embed/youtu.be/vimeo 四形；不可解析 ⇒ nil（等同未填）。
- **external_video_url**：官方 YouTube embed 形
  `youtube.com/embed/{id}?params`（例逐字）；Vimeo＝
  `player.vimeo.com/video/{id}`（Vimeo 官方嵌入形，Shopify 頁未逐字給出
  ⇒ 標 V）。參數 CGI 編 query；回 `ExternalVideoUrlResult`（String 子類
  攜 host 型別——同 ImageUrlResult 設計；只進屬性值不做 Liquid 屬性存取）。
- **external_video_tag**：官方 iframe 例逐字（frameborder="0"、
  allow="accelerometer; autoplay; encrypted-media; gyroscope;
  picture-in-picture"、allowfullscreen、src、title）；輸入官方兩形
  （media object／external_video_url 結果）都通；額外參數 ⇒ HTML 屬性；
  不可識別 ⇒ 空字串（保留原 stub 的安全語義）。
- **video_tag**：URL 字串形出 `<video>`（ours 救援形——Ella video snippet
  自載明支援 URL）；布林參數＝布林屬性、false/nil 略過、`image_size`
  媒體管線參數不落 HTML；media 物件 sources 形同函式已接（資料模型面
  另輪）。
- SettingsDrop coerce 加 `video_url` 分支。
- 測試 VC1–VC4；突變 2/2 殺（stub 化 embed、coerce 回原值）。
