### 🔴 錯的不只字重

**`--t-xs`「一格塞了兩個字重」**：原記單一 `12 / 16 / 500`，
乾淨值是**表格內容 450**（`span.Polaris-Text--bodySm`）與**欄位標題鈕 550**
（`button.Polaris-Table-TableHeadingCell__SortableHeadingButton`）——**500 兩邊都不是**。

**`--t-sm` 的用途欄寫錯了**：右欄記「按鈕、tab」，
但頁首動作組按鈕與檢視 tab 的**標籤**實測是 **12px/16px/550**，**不在這一階**。
該階的 UI 預設是 **450**（輸入框，shadow 內自宣告、免疫），
同階另有側欄一級項 **550**、卡片／區段標題 **600**。

**`91` §15 的 pill**：原記單一 `13px/500`，乾淨值是**兩個**——
①button 本體 **400**（原生 `<button>` 的 UA 預設，從未被重設）
②標籤文字 **450**。另附帶量到 pill 內的值徽章 = **550 / 12px / 16px**。

**`91` §15 的狀態 badge**：**字級也錯**——原記 `13px/500`，
乾淨值是 **550 / 12px / lh 16px**（原記量到的是不繪製的 host，屬「量錯層」）。

### ✅ 一條懸了很久的錯誤建議正式作廢

乾淨值是 **450**——**與我方 `--fw-body` 完全一致，根本不存在「字重差 50」**。
本節與 §19.6 **兩條獨立路徑各自量到同一個值**。⇒ 該建議作廢。
