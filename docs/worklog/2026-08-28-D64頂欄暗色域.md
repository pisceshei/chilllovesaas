## 已完成的工作 (Done)

### ① 取證：本尊的頂欄不是「深色頂欄」

2026-08-28 於 `/products`（本機 Chrome，非內嵌）實測：頂欄 `_TopBar_1scp5_1` 只寫
`background: var(--p-color-bg)`——**自己沒有指定任何深色**。深色來自父層
`Polaris-ThemeProvider--themeContainer`，那一層把同一組語意 token 換成暗值。

亮／暗對照 13 組（`bg` #f1f1f1→#0a0a0a、`bg-surface` #fff→#1a1a1a、
`text` #303030→#eee、`icon` #4a4a4a→#dcdcdc、`border` #e3e3e3→#ffffff17 …）
全表在 `docs/DECISIONS.md` D63 之後的 D64 條目。

🔴 **`*-inverse` 家族兩邊完全相同**——它們是絕對參照，不隨主題翻。
頂欄背景是**暗域的 `bg`**，殼層底色是**亮域的 `bg-inverse`**，
兩者恰好都是 #0a0a0a 但**來源不同、不可互代**。

### ② 三件事是同一個視覺系統

`main` 有 `border-radius: 12px 12px 0 0`，祖鏈是
`_DarkOverlay`（透明）→ **`_Frame` #0a0a0a** → `_AppFrame` #0a0a0a
⇒ **圓角處露出的就是那層暗底**。

側欄實測 `background: rgba(0,0,0,0)`、`border-width: 0`、寬 240
——直接踩在內容面板上。不透明側欄會**蓋住面板左上圓角**，只剩右邊露暗底 ⇒ 不對稱。

⇒ **暗底、圓角、透明側欄必須一起做。**

### ③ 實作

- 值全部放 `:root`（`--dk-*` 14 個 ＋ `--bg-inverse`）——`check-tokens-sync.rb` 只同步
  `:root`，值寫在別處會在原型與 `admin.css` 兩邊各自漂移（C-2 事故形態）。
- `.cl-scope-dark` **只做語意名重新指向**，不含色值 ⇒ 暗域裡的元件一行 CSS 都不用改。
- `.cl-topbar` 掛 `cl-scope-dark`、背景 `var(--bg)`、刪 `border-bottom`。
- `.cl-admin-shell` → `var(--bg-inverse)`；`.cl-app-frame` → `var(--bg)` ＋ 上圓角。
- `.cl-sidebar` 桌機透明無框；**行動抽屜補回 `background: var(--surface-2)`**。
- 原型同步（含 markup 的 `class="topbar cl-scope-dark"`）；`AdminShell.tsx` 加 className。
