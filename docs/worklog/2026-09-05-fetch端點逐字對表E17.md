  6. `q=id:A OR id:B` 搜尋語法（recently-viewed 先前回空）；序＝relevance（本尊三組查詢實測，與 query 序無關）。
  7. 搜尋結果 `product.url` 帶 `?_pos=…&_sid=…&_ss=r`。
  8. `product.collections` 含手動系列（compare 表系列欄先前空）。

  10. predictive JSON：`compare_at_price_*` 無值＝`"0.00"`、`featured_image` 五鍵 null 物件、`\/` 跳脫（`Storefront::AjaxJson`）。
  11. `img_url` 對 nil ⇒ 平台無圖佔位 URL（自繪 gif 路由）；`image_url` 對 nil 仍 error（E12）。
  12. `date` 濾鏡用店時區（`priceValidUntil` 差一天；hoko 時區 +08:00）。
  13. 新端點 `/products/{handle}.js`（本尊 .js 形：無 content、url 在 options 後、變體 22 鍵、店時區時戳、預設變體 Title 選項）與 `.json`（REST 形）；
      recommendations JSON 改同 `.js` 形；Liquid `product | json`／`variant | json` 形**不動**（同日複驗 Ella 商品卡 data-json-product 仍為 83 §12.2 形）。

  15. Normalizer 身分規則：替代模板 id、`_sid`／`_psid`、商品 id 屬性族、`{id}A{17}__`、`template--T__…-{id}"`、國旗 CDN 主機。
