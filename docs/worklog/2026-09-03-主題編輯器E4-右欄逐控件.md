## 已完成的工作 (Done)

- 依 `docs/research/100-theme-editor-live-teardown.md` §3／§3.1 與官方 input-settings 逐字重做右欄：
  - 面板殼：標題列（type icon＋顯示名＋「…」＋「×」）、「…」＝Copy／Duplicate／Rename／Hide⇄Show／Edit code／Remove（紅）、

    （展開寫 URL `customCss=true`）、紅色 Remove section／block；static block 不出 Duplicate／Remove。
  - `visible_if` 求值器（前端純函式）：官方語法句＋Ella 值域（`== != > < >= <= contains`、`and`／`or` 由右往左、只有
    false／nil 為假、無括號）；三作用域 block／section／settings；fail-open；隱藏不清值。
  - 逐型別控件：range（滑桿＋數字框＋單位、step 小數位）、select（optgroup）、radio／text_alignment（分段）、checkbox
    （toggle）、color（色票＋HEX＋popover SV／色相／透明度，alpha ⇒ rgba）、color_scheme（Aa 預覽＋清單＋Edit）、
    color_scheme_group（縮圖格）、font_picker（整面選字型：系統／其他兩組＋字重＋完成）、image_picker（虛線框 Select ⇒
    檔案庫 modal ⇒ `shopify://shopify/files/{filename}`；已設值 ⇒ 變更／移除）、link_list（選單名 ⇒ 取代／編輯／移除選單）、
    url（"Paste a link or search"）、video_url（accept 驗證）、text／textarea／number、html／liquid（行號碼編輯器）、
    richtext／inline_richtext（迷你 RTE；inline 無 Enter／底線）。
  - 「…」ops：`duplicateNode`（section／任意深度 block）、`copyNode`／`pasteNode`（左樹右鍵 Paste 解灰）。
  - 佈景設定手風琴共用同一控件庫＋`visible_if`；佈景設定面板點 font_picker ⇒ 頁面在右欄承接整面選字型。
- 後端：`translate_defs` 保留 `visible_if`／`alpha`／`accept`／`definition`／`role`／`metaobject_type`；section schema 加
  `theme_settings`（liquid 內 `settings.<id>` 引用，排除 `section.settings.`／`block.settings.`）；新欄 `fontLibrary`；
  bootstrap 同文件加 root `menus`。
- 外部語義：input-settings 全型 default 規則、visible_if 語法、Liquid operators 由右往左／真假值逐字進
