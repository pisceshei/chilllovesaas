# Handoff：G4 步 16d schema 驅動控件（2026-09-01）

## ①我改了什麼

20 步方案步 16 第四包。base＝main `5339b01`，分支 `g4/step16d-schema-controls`。
sectionSchemas＋SchemaLocale（t: 解析）＋設定面板 schema 驅動。逐檔＝worklog。

## ②為什麼這樣改

- schema 驅動而非值 typeof：16b 的 typeof 分派看不到 default/range 邊界/
  options 值域（26 §5 全表在庫）；typeof 分派降級保留＝缺 schema 主題仍可編輯。
- default 不物化：本尊 settings_data 只存覆寫（24 §2.5）；ED8 反向斷言釘死。
- t: 解析放 server（兩個 resolver 共用），不下放 client——client 不該知道
  locale 檔佈局。

## ③還有什麼沒解決

- 16d2 佈景設定寫回（themeSettingsUpsert＋touch）；16e 資源選擇器＋code editor；
  visible_if；生產煙測待部署。

## ④下一個人要注意什麼

- SettingControl 的 onChange 一律經 setSetting（applyOp 快照棧）；新控件型別
  加 switch case，不要繞過 effective 值解析。
- SchemaLocale 是顯示層 fail-open（回原鍵）；若要對齊本尊 "Translation
  missing" 要同時改 E5 斷言。
- 16d2 的 settings_schema 分組＝陣列首項 theme_info、其後 {name, settings[]}
  （24 §2.5）；color_scheme_group 只在 settings_schema.json 出現（26 §5）。
