## ② 為什麼這樣改

- 不能放寬 admin CSP（信任邊界：admin 是第一方代碼、主題是商家內容——`theme_csp.rb` 檔頭③）。
- 不用 `document.write`／innerHTML 換整頁：前者仍是舊文件的 policy container 但要重跑橋腳本與所有 theme JS 的初始化時序；
  後者 inline script 不執行。真實 URL 重載＝本尊做法（預覽 iframe 導航到帶草稿的預覽網址），主題 JS、base URL、CSP 全部自然正確。
- 草稿放 cache 而非 DB：未儲存草稿是暫態；TTL 到期即消失，不留租戶資料。
