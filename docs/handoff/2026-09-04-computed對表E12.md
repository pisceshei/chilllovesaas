## ② 為什麼這樣改

- 工具零依賴、走本機 Chrome：鐵律 1 不引重型依賴；乾淨 profile 消融擴充污染（memory `measurement-env-contamination`）；CDP 能拿 computed、
  命中規則與網路診斷，是唯一能解釋「同標記不同 computed」的路。
- svg 子節點不比：佔位插圖本體是唯一例外；圖示 path 幾何由盒＋viewBox 決定，標記差由 HTML 對表負責。
- `image_url` nil 改成 raise：本尊逐字證據＋Liquid 5.13 對 assign／output 的既有差異，使兩處證據（sticky-atc 錯誤文字、add-to-cart 空字串）
  同時成立；先前的「空字串」只滿足一處。
- SRA 完整 id 依宿主模板解析：本尊 id 全域唯一，Ella JS 在 /search 上取商品模板的段；不做這條 `section_id` 在任何頁面的官方語義就只對了一半。
- recommendations 補位：本尊行為可見（兩卡）但規則未逐字 ⇒ 最保守的「其他可見商品依建立序」，登記 V。
- 被推翻的假設：「元素數差是主題 JS 沒跑」（診斷零例外，實為佔位插圖）、「搜尋圖示差是 CSS 規則不同」（規則相同，details 關閉態報告值差）。
