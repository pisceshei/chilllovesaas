# 交接 · D61 刪除視口相對字級（2026-08-28）

輸入 base＝`5b2e2e7`（＝`origin/main`，#174 已合併）。分支 `m2/d61-h1-clamp`。

使用者裁定的五項執行順序中的**第 1 項**。配對 worklog＝`docs/worklog/2026-08-28-D61視口字級刪除.md`。

## ① 我改了什麼

刪掉原型裡**兩條**用視口相對單位（`vw`）做字級的規則：
- `h1{font-size:clamp(17px,4.6vw,20px)}` → **整條刪除**，基底規則接手
  （三寬度實測皆 18/24/600/−0.14994px）
- `.hero-hello h2{font-size:clamp(19px,5.4vw,24px)}` → **改用 `@container cl-page (max-width: 768px)`**，值 `--t-500`／`--lh-600`（20/24）

改後全檔 **clamp 字級 0、vw 字級 0**。

## ② 為什麼這樣改

**本尊的頁面標題沒有 mobile 覆蓋**：全表 29 條 `*-when-mobile-p1s0`（25 字型 ＋ 4 圓角），
`display-small` 與所有 `font-weight` 一條都沒有。六頁實測非 toolbar 形態一律 18/24/600/dense。

**hero 則相反——本尊有窄版分支**，但用的是 `@container (max-width: 768px)`（**容器寬不是視口寬**），
值 20/24。我方原本的 clamp 機制與值都不對。

**被推翻的假設**：
- ~~射程只有 h1 那一條~~ → 掃全檔發現**第二條**（`.hero-hello h2`）。
- ~~本尊頁面標題在任何條件下都是 18px~~ → 反駁方消融證明 `.toolbar .heading` 形態走
  **body-medium**，而那一階**有** mobile 覆蓋（13→16）。正確表述要限定「非 toolbar 形態」。
