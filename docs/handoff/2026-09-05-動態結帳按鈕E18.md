## ② 為什麼這樣改

- **不抄本尊 JS／CSS、只同形介面**（鐵律 9）：主題依賴的是 tag／id／class／屬性名／`Shopify.PaymentButton.init()`／`portableWalletsCleanup` 名稱；
  bundle 本體（386 KB）與樣式表本體我方自寫，Normalizer 把 bootstrap script 本體視為替身。樣式回溯演算法逐步對位是為了**主題無關**（Kalles／Minimog 的舊
  `.shopify-payment-button__button` CSS 也要被接住）。
- **cartCreate 而非 `/cart/add`＋`/checkout`**：抓包證實本尊「立即購買」另建 Storefront API cart、不動買家購物車（官方 "skip the cart"）；照做才不會
  污染 Ajax 車，且順手立了 `/api/:version/graphql.json` 入口（T11 預留）。
- **被推翻的假設**：①「本尊骨架是 disabled 靜態骨架、無錢包時停在骨架」——錯，bundle 一定升級成 buy-it-now 按鈕（無第三方錢包時 fallback＝buy_it_now）；
  ②「`5rem` 是主題直接宣告的自訂屬性」——錯，是 bundle 從 Ella `section-main-product.css` `.shopify-payment-button__button{min-height:5rem}` 回溯出來的；
  ③「headless 對本機逾時是 host 問題」——錯，是自訂元素在 MutationObserver 回呼裡對自己 set 屬性的無窮迴圈。
- **未採方向**：cart permalink（`/cart/{variant}:{qty}`）當按下流程——文檔功能但非本尊 buy-it-now 的實際傳輸；另包再做 permalink 本身。
