## ② 為什麼這樣改

- 使用者裁定 D79；100 §4／§8.1 給 picker 形態（貼左欄右緣、清單≈250＋預覽≈390、分段、Generate、扁平可用清單→分類收合、
  (1/1) 灰化、插入線）；使用者 2026-09-03 的本尊截圖同形。
- 清單以 preset 為單位：本尊列 "Header - Classic (1/1)"／"Product list: Carousel"＝preset 名（fixture 統計：section 一支
  16 個 preset）；沿用 E3 的 `pickerEntries` 過濾＋(n/limit)，picker 只吃 items（不重複一份過濾）。
- 被推翻的假設：①「preset blocks 只有 hash 形」——Ella 有 2 個 array 形（含巢狀），且官方 preset 允許 array，故兩形都做；
  ②「block picker 的分類直接取 section 本地 def」——本地 def 多半沒 category，退回同型 theme block 的 category；
  ③「生成 id 去掉前導底線」——Ella 私有 block `_parent` 應得 `_parent_xxxxxx`，改保留。
- 未採方向：picker 右欄用 `draft_section` 渲染縮圖（需主題 CSS 語境，另包）。
