  真正的時序是 Vite 首次建置約 3.58 秒後才由 React `Navigate` 完成客戶端路徑切換。
- **未採：直接增加 Capybara 等待時間或改 assertion。** 本包只處置 Codex review 點名的文件問題，
  system spec 沒被點名；鐵律 17.2 要求只登記，不能以「同時讓閘門綠」擴散射程。
- **未採：把第二次暖快取通過視為永久修復。** 冷建置仍可在乾淨 runner 重現；斷根必須另包驗證

## ④ 下一個人要注意什麼

1. Windows 原生執行時把 `C:\Program Files\Git\bin` 放在 PATH 前端，使用 `bundle.bat`、
   `pnpm.cmd` 與 `ruby bin/rails`；不要讓 WSL `bash` 或 extensionless wrapper 製造第二種假失敗。
2. 先以絕對 gem glob canary 證明執行層可枚舉依賴，再跑 Rails gate；本文件定稿時的定向結果為
   `1 example, 0 failures`，第一次完整復跑為 29/29。原子收尾須從 setup 起完整跑 29 閘門；若
   失敗就停止 commit，不能只保留前一次綠燈。
3. 不修改 system spec。若另立斷根包，必須清除／隔離 Vite test build 以重現 cold path，並另跑 warm
   path；兩者都有可追溯結果才可結案。
4. 所有最終數字回填後會改變受驗內容，須再跑一次完整閘門，且 push 前仍要做鐵律 15.1／15.2。
