# 交接 · D57 決定 C 包 C-1：字體系統三層化（2026-08-28）

輸入 base＝`2b16546`（＝`origin/main`，D56 #169 已合併）。分支 `m2/decision-c1-type-tiers`。

四個設計決定的**第三個**落地包。配對 worklog＝`docs/worklog/2026-08-28-D57字體三層.md`。

## ① 我改了什麼

原型 `:root` 字體區塊整段改寫成三層：**L1 原語**（字級 13／行高 8／字重 4／字距 4）
＋**L2 角色階 16 個**（與本尊 1:1，軸集也 1:1）＋**L3 過渡階**（舊 `--t-{2xs..3xl}`，值指回 L1）。

修掉四個落在本尊值域外的 `500`：`--fw-control`→550（14 處）、`--fw-md`→550（3）、
`--fw-xs`→550（1）、`--fw-xl`→600（1）。

## ② 為什麼這樣改

**舊結構在數學上表達不了實測**：本尊在 12px 這一個字級上同時有 450／550／600 三種字重。
而我方自己的程式碼早就在違反那個配對——`--t-xs` 消費 **265** 處、`--fw-xs` **1** 處、
`--fw-sm` **0** 處 ⇒ 配對只活在註釋裡。

**被推翻的假設**：
- ~~只要把 size token 的值改成本尊的就對了~~ → **不行**。`--t-lg`（16px）同時服務
  SERP 模擬標題（**模仿 Google，不是 admin 元素**）、modal 標題、帳目數字、統計數字。
  本尊卡片標題是 13px，但改 `--t-lg` 會一起縮掉 SERP。⇒ 必須由**元件指到角色**。
- ~~body-* 角色不帶字重，所以我方也不用管~~ → **token 層不帶，渲染層一定要 reset**。
  本尊 `.Polaris-Text--bodyXs/Sm/Md/Lg` 四個 class 都顯式寫
  `font-weight: var(--p-font-weight-regular)`，live control 證實父層 750 → 子元素 450。

## ③ 還有什麼沒解決

1. 🔴 **包 C-2（元件層遷移）未做**——這是讓畫面真的對齊的那一步：
   卡片標題 16→13（heading-md）、頁面標題 20→18 ＋補字距（display-sm）、
   Modal 標題統一 display-sm、表格儲存格顯式 450／主連結 550、側欄一級 550／二級 450、
   欄位輔助文字用 details-text。🔴 **SERP 模擬標題不遷移**。
2. 🔴 **包 C-3（清硬編字重）未做**：`admin.css` 9 處、原型 32 處在本尊值域外（400/500/700）。
   已登記 `91` §3.30 W-3／W-4；機械閘門待 **G-06** 裁定。
3. ⚠️ **未做 live 視覺並排比對**（鐵律 13.1 三寬度）。本包 19 個消費點的渲染字重
   會從 500 變成 550/600。
4. ⚠️ **L3 尚未淘汰**，`--t-xs` 與 `--t-300` 兩套命名暫時並存。**新程式碼直接用 L2 角色階。**
5. ⚠️ **class 層（`.t-{role}` / `.fw-{abstract}`）未建**。建的時候
   **`.t-body-*` 必須顯式寫 `--fw-regular`**（本尊是 reset 不是繼承）。
6. ⚠️ `--lh-2xs: 14px` 是**我方自有值**（本尊行高階無 14），已在 token 表原處標明。

## ④ 下一個人要注意什麼

- **入口**：`docs/DECISIONS.md` **D57** → 原型 `:root` 字體區塊的長註釋（三層各自的理由都在那裡）。
- 🔴 **不要試圖「把 `--t-lg` 改成 13」**。它服務多個角色，其中 SERP 模擬的 16px 是對的。
  正確做法是把**卡片標題那個元件**指到 `--type-heading-md-*`。
- 🔴 **本尊的行高階與字級階是獨立編號的**（`--lh-500` 是 20px，不是「第 500 階字級的行高」）。
  照抄時不要以為 `--t-500` 配 `--lh-500`。
- 🔴 **字距 `normal` 用 rem、其餘用 em**（本尊如此）。不要統一單位——
  上一輪研究就是把 `--ls-*` 抄成 mobile 主題的值、單位還從 rem 變 em。
- 🔴 **6 個角色只被新 `s-*` 元件消費**（button-label／details-text／input-label(-small)／
  avatar-initials(-long)）⇒ 只掃 `.Polaris-Text--*` 只會看到 10 個角色，會漏掉一半。
- ✅ **字體 token 不受 theme provider 污染**（實測 dark scope diff = 0）
  ——與顏色不同，量字體不必逐元素確認 scope。但**字重仍要停用擴充功能污染源**。
