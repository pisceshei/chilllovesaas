路徑選擇，沒有證明 workflow 本身有 33 個語法錯誤。下一輪在同一 PowerShell process 前置
`C:\Program Files\Git\bin`，再從 setup 起完整重跑。配對 worklog：

## ② 為什麼這樣改（含被推翻的假設）

- **被推翻：Windows 上命令名 `bash` 唯一指向 Git Bash。** 實跑輸出是 `/bin/bash` 且不能
  開啟 `C:/...`，與 Git Bash 的路徑語義不符。
- **未採：只把四個失敗項改成通過。** 它們的退出碼是真失敗；只能修正執行環境後重新實跑。
- **未採：趁機修改 checker 或 `bin/ci`。** 使用者點名的是鐵律 handoff，鐵律 17.2 禁止擴散；
  本次只固定本地執行 PATH 並登記證據。
