- 🔴 **被推翻的假設二（上一場文檔的）**：「70 commit 從來沒推上 GitHub」——證據只是認證失敗。實際 remote 有被遺忘的活動史。教訓已寫進完整性清單 §④：**認證失敗時不得對 remote 內容下任何結論**。
