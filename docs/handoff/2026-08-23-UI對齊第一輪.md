## ② 為什麼這樣改（含被推翻的假設）

- **「檢查 token 名字就夠」被推翻**：漂移的形態是同名不同值（`--bg:#f4f4f5` vs
  `#f1f1f1`），名字檢查恆綠 ⇒ 判準改逐位元組。
- **「全文不得出現 :root{」自我推翻**：規則說明文字本身含這個字串，第一版實跑
  即被自己判紅（[[self-invalidating-claims]] 的又一例）⇒ 判準改「行首起頭」。
- **Windows Ruby text mode**：讀寫各翻譯一次行尾、互相抵銷，「逐位元組相同」在
  行尾其實不同時照樣綠 ⇒ 檢查與同步端一律 binread/binwrite。
- **route 手寫清單被推翻**：側欄 20+ 項逐條手寫路由必然出縫（點得到、404）⇒
  placeholder 路由由導覽資料表派生。
