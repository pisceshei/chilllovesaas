## ④ 下一個人要注意什麼

- **入口**：`docs/DECISIONS.md` **D55** → `docs/design/111` §16.1／§14.7／§20.8 的 2026-08-28 更正。
- 🔴 **量 `--p-*` 前先問「這個元素在哪個 theme scope」**（`111` §20.8 第 4 條）。
  三頁各有 **113 個元素**算出與 root 不同的值，**頂欄就在其中**。
  要證明「這個 token 是那個顏色的來源」，**用消融不用相關性**。
- 🔴 **`@container` 與 `@media` 的條件不能用 `var()`，而且是 fail-open**
  ——Chrome 151 實測會解析成 `CSSContainerRule` 且帶子規則，但永遠不匹配。
  本尊的 `--p-breakpoints-*` 五顆全站零消費，同一個成因。
- 🔴 **任何「預期為零」的檢查都要配 canary**。本輪在驗證自己的宣稱時**連踩兩次 fail-open**
  （`\b` 被寫成 backspace 控制字元；修好後 `\b633\b` 仍抓不到 `633px`），
  兩次都回報「0」而理由與我以為的無關。固定處理見 worklog 末節。

  剩下的字串被 shell 當命令執行。用 `<<'PYOUTER'` 這類不會撞名的。
- **本包純前端 CSS/TSX ＋ 文檔**，未觸及 18.3 類檔案，無 schema、無費用 ⇒ 依 D40，
  `quality` ＋ `test` 兩個 job 綠即可合併。
