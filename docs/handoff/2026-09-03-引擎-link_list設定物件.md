## ② 為什麼這樣改

- Ella `snippets/header-menu.liquid` 逐字 `{%- for link in header_settings.menu.links -%}`：setting 必須是物件；本尊同一
  JSON 在真店渲染出 首頁／目錄／聯絡我們（2026-09-03 截圖）。
- 走 `linklists` 全域 drop 而不是自己再查一次：同一 shop 語境、同一 url 前綴、同一 miss 計數（`count_miss`）。
- 被推翻的假設：「seed 了 main-menu 選單就會出現」——資料對、設定對，卡在型別強轉。
- 規格首版沒包 `ActsAsTenant.with_tenant` ⇒ `Menu.find_by` 丟 `NoTenantSet` 變成 "Liquid error: internal"；
  PageRenderer 本來就在租戶語境內跑，規格照做即可（不是程式缺陷）。

## ④ 下一個人要注意什麼

- 其他資源型 setting（`product`／`collection`／`page`／`blog`／`article`／`url` 的 `shopify://` 形）在 `coerce` 仍是原值
  字串——E4 做對應控件時一併補 drop 化並各給規格。
- 引擎規格要包 `ActsAsTenant.with_tenant(shop)`，否則 acts_as_tenant 表的查詢會丟 `NoTenantSet`，Liquid 只顯示
  "Liquid error: internal"，要用 `Liquid::Context.new(…, rethrow_errors = true)` 才看得到例外。
