## 6. 關鍵事實（本輪取證，全文在 external-facts §G22／§G23）

1. **官方 `localization`／`country` 物件**逐字（§G22）；本尊 header 區段 SRA：31 國、zh-CN 在地名碼位序（丹麦／保加利亚／克罗地亚…）、每列 `($HKD)`、當前 TW；
   首頁初始 HTML 零 `/localization` 表單、只有 `dropdown-localization__button`＋`<section-fetcher>`（Ella `language-country-localization.liquid` L275–L334 分支）。
2. **本尊語言 URL**（§G23）：`/` 200 `lang="zh-CN"` `Shopify.routes.root = "/"`；`/zh-hans/` 404；`/zh-hant/`、`/en/`、`/en/collections/all`、`/en/products/acme-tee`、
   `/zh-hant/pages/contact` 200；市場不產生前綴（`/en-us`、`/zh-hant-hk` 404，§G21）。Ella 主題層 `<link rel="canonical" href="https://hoko.vip/en/collections/all" canonical-url="https://hoko.vip/">`。
3. **本尊 hreflang**：每頁六條 `x-default`／`zh-Hans` → 無前綴、`zh-Hant`／`en`／`fr`／`ja` → `/{lang}…`；零地區碼、五市場不進矩陣；`/zh-hant/` 頁集合與首頁逐位元組相同。
4. **本尊 `POST /localization`**：①`country_code=US` ⇒ 302 同語言＋`localization=US; path=/; expires=一年; SameSite=Lax`；②`language_code=en&country_code=TW` ⇒
   302 `/en/…`＋`localization=TW; path=/en`；③`country_code=JP&language_code=ja` ⇒ 302 `/ja/…`＋`localization=JP; path=/ja`。`GET /` 帶 `localization=US` ⇒
   `Shopify.country = "US"`、`Shopify.currency` 仍 HKD。官方 form 頁只說 "select their preferred country so that they're shown the appropriate language and currency"，cookie 官方未載明。
5. **本尊 sitemap**：index 列 `sitemap_agentic_discovery.xml`、`sitemap_{products,pages,collections,blogs}_1.xml`，再依每個非預設語言列 `/zh-hant/sitemap_*_1.xml`…（每語言一組子表）。
6. **官方 help**："Use subfolders, such as `example.com/de`, or subdomains, such as `de.example.com`, for language-specific URLs."；子資料夾市場 "such as `example.com/fr-ca`"。

## 11. 這一段的教訓（下次別再踩）

- **doc-claims 本機假綠**：新 worklog／handoff 未 `git add` 時 R4／R5 根本沒掃它（只掃 `git diff origin/main`）⇒ 凍結前 `git add -A` 再跑，或 commit 後用 `--base origin/main`。
- **sed 批改 URL 的雙斜線**：`"/en-hk"` → `"/"` 後，drop 測資 `url_prefix: "/"` 會產生 `//search`；真前綴只能是 `""` 或 `/zh-hant`（本輪兩例：filters_gap T2、storefront_blog LN1）。
- **整合測試的 cookie jar**：`post "/localization"` 的 Set-Cookie 會留在 jar，之後的 `get` 自動帶上 ⇒ 要測「無 cookie」先 `cookies.delete("localization")`。
- **租戶脈絡**：`PrefixIndex.resolve`／`Hit#effective_country_code` 在 unit spec 裡沒有 tenant ⇒ 服務層自己包 `ActsAsTenant.with_tenant`，不要靠 controller 的 middleware。
- **突變還原用 `git checkout --`**：先 commit 再跑突變，跑完 `git diff HEAD` 必須空（memory `mutation-revert-trap`）。
- **Bash tool heredoc 會吃反斜線**（`\\A` 變 `\A`）：含 `\` 的腳本用 Write 工具寫檔再執行。
- **閘門後再動檔案＝重跑**：填閘門表那一次只重跑 doc-claims 兩支並在 worklog 明寫；不要為登記刷新 head（突變結果進 PR body）。
- **preview_start 不可用**時不要退回用 Bash 起 dev server 硬撐（本輪略過本機 server 探針，改以 bt3 公開站 curl 為準）；要修就修 launch.json 並進 commit。
