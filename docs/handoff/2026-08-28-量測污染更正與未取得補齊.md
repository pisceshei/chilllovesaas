## ① 我改了什麼

**主軸**：發現使用者 Chrome 的擴充功能注入
`body, body :not(svg):not(svg *):not(img):not(video):not(canvas) { font-weight: 500 !important }`，
它把字重**雙向**改寫（450 拉高、550 壓低成同一個 500）。🔴 **shadow DOM 不是無條件免疫**（同日二次更正）：`font-weight` 是可繼承屬性，shadow 內未自宣告它的繪製盒仍會繼承宿主被污染的值。判準是「該元素自己有沒有宣告 `font-weight`」，必須逐項做 clean/dirty 配對。全文＝`docs/design/111` §20.3。
⇒ **看到 500 無法回推真值，只能重量。**

逐項更正 **118 條**，分落五個檔：
`21` §5.6（22）／`77` §7.6（31）／`81` §8.6（29）／`82` §16.6（7）／`113` §1.6（29）。
方法論主文＝`docs/design/111` **§20**。

## ② 為什麼這樣改

**為什麼不是直接改數字而是加更正註**：鐵律 19.5——更正不得抹除歷史。
`docs/research` 的 teardown 是**證據紀錄**，原文要留著才能看出「當時量到什麼、為什麼錯」。
`docs/dev`（終態層）才直接改成現值。

**被推翻的假設**：

1. 我原以為「1280 取不到」是因為螢幕只有 1024。**錯**——`screen` 是 **2560×1440**。
   真正的原因是視窗離屏（`screenX ≈ -32000`）、渲染面凍結。
   實測請求 700／1280／1500／2400 四種寬度，`innerWidth` **一律 945**，
   而 `resize_window` **每次都回報成功**。
2. 我原以為「本尊有兩套設計系統、字重值不同」。**部分錯**——字級確實不同（13 vs 12），
   但**字重那一欄的差異是污染造出來的**。
3. 我原以為記到的 `500` 可以統一還原成 450。**錯**——污染是雙向的，
   `.Polaris-Text--bodyMd` 的乾淨值是 **550**。
4. 我原以為量測的元素就是繪製文字的元素。**錯**——`s-*` host 常是 `display: contents`，
   包裹 `<a>` 只繼承 body。原記載的單一「500」同時掩蓋了包裹層與繪製層兩個不同的值。

## ③ 還有什麼沒解決

1. 🔴 **`47` 與 `64` 的 font-weight 值未複驗**（`110` G12）。同一台機器量的，
   `64` §3 的「Pill、主要按鈕 13/20/**500**」正是污染特徵。兩處已加守衛。
2. 🔴 **擴充功能仍然啟用**。我只能在 CSSOM 層暫時停用，每次頁面重載都要重做。
   根治需使用者到 `chrome://extensions` 停用——**瀏覽器設定不在我的授權範圍**。
3. **1280／1440 的 live 取樣仍不可得**。本輪 ≥1024 的結論來自樣式表規則本體與門檻代數，
   **不是該寬度下的實測像素**。
4. **`@container` 軸只有單一資料點**，「視口 1280 → 容器 1024」是代數推導非量測。
5. **樣式表集合不是全站窮舉**（13 個 admin 區段；未含 Apps 各頁、Settings 子頁、
   訂單／顧客詳情、結帳編輯器、主題編輯器）。
6. **頂欄搜尋 overlay 展開態未取得**（離屏視窗下點擊與 `Ctrl+K` 都觸發不了）。
7. 🔴 **`91` 第 19 節與 `94` §4 未做乾淨重量**（G12 射程已擴張）。兩處已加引用守衛，
   但**沒有重量**——`91` 27 項、`94` 41 項的字重值仍不可引用。
8. **本包未跑 CI**（寫作時）。

## ④ 下一個人要注意什麼

- **入口**：`docs/design/111` **§20**（污染方法論）→ 各檔的更正節 → `112` §2.2（換值處置）。
- 🔴 **量任何 `font-weight` 之前先停用污染源，且每次導航後重做**：
  ```js
  [...document.querySelectorAll('style')].find(s => s.id === 'font-bolder-style').sheet.disabled = true
  ```
  量完還原成 `false`。這只切 CSSOM 旗標，不動使用者的擴充功能設定。
- 🔴 **量文字樣式一律量「實際繪製文字的元素」**：判準是 `childElementCount === 0`
  且有非空 `textContent`。`s-*` host 常是 `display: contents`，量它會得到與外觀無關的值。
- 🔴 **不得引用 `47` §D 與 `64` §3 的任何字重值**，直到複驗（G12）。
- 🔴 **不要再試 `resize_window`**——它會假成功。要寬度相依的事實，走樣式表窮舉
  （`document.styleSheets` 全部同源可讀）。
- 🔴 **我方 em 化時不得寫出 `(min-width: A + B)` 這種裸 `+` 條件**——
  本尊自己就有一條這樣的死規則，**本地檢查與 CI 都不會報錯，只會靜默失效**（`91` §3.29 W-5）。
