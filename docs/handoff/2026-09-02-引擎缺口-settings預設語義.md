## ① 我改了什麼
- `schema_defaults` 補官方隱含預設（checkbox false／select・radio 第一 option／color_scheme 佔鍵），
  `coerce` 的 color_scheme 三段退回（default → 第一組）；四條 settings 路徑共用。
- 驗證：S1–S5 綠（S5 為 Minimog 真主題 conformance，兩個 theme 層鍵不再 miss）；三個突變各自轉紅；
  blocks／wrapper／conformance／page_renderer／font_pipeline 回歸綠；rubocop 綠。

## ② 為什麼這樣改
- 官方 input-settings 逐字（取證 2026-09-02）三句就是全部規則；preclassify 對 Minimog／Kalles 各標 10 個
  `ENGINE-GAP?` 鍵，其中 checkbox 型的 nil 讓 `{% if settings.x == false %}` 與 `{% unless settings.x %}`
  兩形都走錯，color_scheme 型的 nil／空字串讓 `color-{{ scheme }}` class 掉字。
- 選在 `schema_defaults` 一處修而不是在 SettingsDrop 補：四條路徑（theme／section／theme block／本地 block）
  都經過它；SettingsDrop 只在 color_scheme 退回時需要 default，故只把該型的整個定義塞進 types。
