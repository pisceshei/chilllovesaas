## ②為什麼這樣改

- lifecycle mutation 走 ours 合一形（官方按 code/automatic 分套；我方支數可複驗：
  `git grep -c "field :discount_" app/graphql/types/mutation_type.rb`）：method 已在
  資料列，客戶端只有 admin SPA 一個（28 §0 的 API-first 前提）——分拆是純樣板
  膨脹；PR 描述明載此偏離。
- basisPoints Integer 對外（官方 0–1 Float）：鐵律 3 的 API 面延伸；顯示層 /100。
- 壞碼「不留殘」：碼留在 checkout 上會讓之後每次重算都報錯（MB4 紅證）。
